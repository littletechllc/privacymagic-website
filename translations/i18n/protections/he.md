Privacy Magic הוא תוסף קוד פתוח ל-Chrome שמגן באופן מקיף על הפרטיות שלכם בזמן הגלישה באינטרנט. דפדפנים דולפים מאוד, ולכן Privacy Magic מספק שכבות הגנה מרובות, כולל [חסימת פרסומות ועוקבים](#blocking-ads-and-trackers), [הגנה על מידע מערכת](#protecting-system-information-fingerprinting), [הסרת פירורי מעקב](#removing-tracking-breadcrumbs), [עצירת דליפות רשת](#stopping-web-leaks), [שליחת אותות פרטיות](#privacy-signals), ו[אכיפת הגנות דפדפן](#browser-protections).

## חסימת פרסומות ועוקבים {#blocking-ads-and-trackers}

ברחבי הרשת, פרסומות, סקריפטי מעקב ופיקסלי מעקב עוקבים אחריכם ללא הסכמתכם באמצעות מגוון שיטות בלתי נראות.

Privacy Magic משתמש ברשימות סינון פופולריות כדי לחסום פרסומות ועוקבים רבים מלהיות מבוקשים על ידי הדפדפן שלכם ברשת. רשימות הסינון גם מסתירות את התיבות הריקות שנותרות כשפרסומות נחסמות בדף אינטרנט. Privacy Magic משתמש בגרסה קבועה של רשימות סינון אלה כך שהתנהגות החסימה של התוסף ניתנת לשחזור מלא וזהה לכל משתמש.

| רשימת סינון | פריטים שנחסמים |
| :--- | :--- |
| [EasyList](https://easylist.to/) | פרסומות, כולל באנרים, סקריפטי פרסום, תמונות ופרסומות וידאו. |
| [EasyPrivacy](https://easylist.to/) | עוקבים, כולל סקריפטי מעקב, פיקסלים, באגי רשת ואוספי מידע אחרים. |
| [Fanboy's Annoyance List](https://easylist.to/) | הודעות עוגיות, ווידג'טים של מדיה חברתית, חלונות קופצים בתוך הדף והפרעות אחרות. |
| [small oisd blocklist](https://oisd.nl/) | דומיינים פרסומיים נוספים. |

## הסרת פירורי מעקב {#removing-tracking-breadcrumbs}

חלק מתכונות הדפדפן פגיעות לשימוש לשיתוף חלקים מהיסטוריית הגלישה שלכם ("פירורים") עם אתרים שונים שאתם מבקרים בהם. Privacy Magic מחזק תכונות אלה כך שהן פחות דולפות.

| פירור | דפדפני אינטרנט סטנדרטיים | Privacy Magic |
| :--- | :--- | :--- |
| דליפות מטמון | דפדפנים מאחסנים נתונים במטמונים מקומיים, כך שכשאתם מבקרים בדף או צופים בו בפעם השנייה, אין צורך לטעון את הנתונים שוב. למרבה הצער, מטמונים אלה דולפים לפעמים ויחשפו משהו על היסטוריית הגלישה שלכם לאתר שאתם מבקרים בו. | Privacy Magic מנקה מטמונים פגיעים כדי שדליפות אלה לא יוכלו להתרחש. |
| מדיניות Referrer | באופן מסורתי, דפדפנים יגידו לכל דף אינטרנט שאתם מבקרים בו מאיזה דף אינטרנט הגעתם! | Privacy Magic מוחק את הדף המדויק (או הנתיב) במפנה, ולמען תאימות רשת, מאפשר רק לשתף את הדומיין. |
| פרמטרי מעקב | עוקבים יכולים להוסיף "פרמטרי מעקב" נוספים לכתובות דפי האינטרנט שאתם מבקרים בהם, כדי שמפרסמים יוכלו לעקוב מי אתם או היכן גלשתם. | Privacy Magic מוחק פרמטרי מעקב ידועים מכתובות אינטרנט כדי שמידע זה לא ישותף עם האתרים שאתם מבקרים בהם. |
| Window Name | בדרך כלל, ממשק ה-JavaScript API של `window.name` מדליף נתונים אם אתם מנווטים בין אתרים באותה לשונית. | Privacy Magic מונע דליפה זו על ידי אכיפת `window.name` נפרד לכל אתר. |

## עצירת דליפות רשת {#stopping-web-leaks}

דפדפני אינטרנט הם יצורים מסובכים! דליפות של מידע פרטי יכולות לנבוע מתכונות דפדפן רבות ושונות. הגישה שלנו ב-Privacy Magic היא לסתום דליפות בכל מקום שבו הן עשויות להימצא.

| תכונה | דפדפני אינטרנט סטנדרטיים | Privacy Magic |
| :--- | :--- | :--- |
| Iframes | iframe הוא "דף אינטרנט בתוך דף אינטרנט." זהו תיבה בתוך הדף שאתם מבקרים בו, שבה דף אינטרנט שני יכול להסתתר ולהשתמש בכל אותן טכניקות מעקב שדף אינטרנט רגיל יכול להשתמש בהן. | Privacy Magic מזריק את כל ההגנות שלו לכל iframe בדף אינטרנט, כדי להבטיח שעוקב לא יוכל לעקוף את ההגנות על ידי הסתתרות בתוך iframe. |
| Service Workers | Service Workers הם תכונת דפדפן המאפשרת לקוד לרוץ ברקע גם כשאינכם מחוברים לאינטרנט. למרבה הצער, Service Workers אלה מסוגלים בקלות לדלוף מידע פרטי. | Service workers מושבתים בדרך כלל בכל האתרים, כדי למנוע דליפות של מידע פרטי שלא ניתן לתקן אחרת. |
| Shared Storage | Shared Storage הוא תכונת דפדפן המאפשרת לצבור ולאסוף נתונים על הגלישה שלכם. אף שנטען שהיא שומרת על פרטיות, תכונה זו העלתה חששות פרטיות חזקים וצפויה להיות מוסרת מדפדפנים. | Privacy Magic מוודא ש-Shared Storage מושבת בכל האתרים. |
| Shared Workers | Shared Workers הם קוד שרץ ברקע ויכול להיות משותף בין אתרים. | Privacy Magic מזריק את ההגנות שלו לכל Shared Worker שנטען על ידי כל אתר. |
| Web Workers | Web Workers הם קוד שרץ ברקע בדף אינטרנט. כמו סקריפטי הדף הראשי, קוד web worker יכול לדלוף נתונים פרטיים. | Privacy Magic מזריק את ההגנות שלו לכל Web Worker בדף, כדי לוודא שעוקבים לא יוכלו להשתמש ב-Web Workers כדי לעקוף את ההגנות. |

## אותות פרטיות {#privacy-signals}

אנחנו מעוניינים לשפר את הפרטיות שלכם בכל דרך אפשרית. לכן Privacy Magic שולח אות לדרוש מדיניות תומכת פרטיות מהאתרים שאתם מבקרים בהם.

| אות | דפדפני אינטרנט סטנדרטיים | Privacy Magic |
| :--- | :--- | :--- |
| Global Privacy Control | ה-Global Privacy Control הוא אות שניתן לשלוח לאתרים שאתם מבקרים בהם כדי לציין שאינכם רוצים שהנתונים שלכם יימכרו או ישותפו. למרבה הצער, רוב דפדפני האינטרנט אינם שולחים את העדפת ה-Global Privacy Control כברירת מחדל. | Privacy Magic מוודא שהדפדפן שלכם שולח את כותרת ה-Global Privacy Control עם כל בקשה לכל דף אינטרנט או משאב מוטמע. הוא גם מזריק אות JavaScript בכל דף ו-iframe. |

## הגנות דפדפן {#browser-protections}

דפדפנים מתנהגים בצורה גרועה לא רק באופן שבו הם מציגים דפי אינטרנט, אלא גם באופן שבו הם שולחים נתונים לחברת האם או לחברות פרסום צד שלישי. Privacy Magic משבית מגוון התנהגויות דפדפן גרועות שהיו מדליפות אחרת את המידע הפרטי שלכם.

| תכונה | דפדפני אינטרנט סטנדרטיים | Privacy Magic |
| :--- | :--- | :--- |
| ביקורת היפר-קישורים | לדפדפנים סטנדרטיים יש תכונה המאפשרת לאתרים "לפנג" שרת מעקב עם הקישורים שאתם לוחצים עליהם. | Privacy Magic משבית את הפינג הזה. |
| עוגיות צד שלישי | תכונת המעקב המפורסמת מכולן. Chrome מאפשר עוגיות צד שלישי שמאפשרות לעקוב אחריכם מאתר לאתר. | Privacy Magic משבית עוגיות צד שלישי כברירת מחדל. |
| WebRTC non-proxied UDP | WebRTC הוא יכולת דפדפן המאפשרת לכם לתקשר ישירות עם משתמשי רשת אחרים. למרבה הצער, אם אתם משתמשים בפרוקסי לדפדפן, דפדפנים מבוססי Chrome סטנדרטיים ידליפו תקשורת WebRTC מחוץ לפרוקסי. | Privacy Magic חוסם את דליפות ה-WebRTC, תוך אפשרות ל-WebRTC להמשיך לתפקד באתרים שמשתמשים בו. |

### השבתת הגדרות Chrome דולפות {#disabling-leaky-chrome-settings}

Chrome מכיל הגדרות מסוימות שסותרות את הפרטיות שלכם: ספציפית, פונקציונליות שאוספת נתונים על הרגלי הגלישה שלכם ושולחת אותם לשרתי Google. הגדרות אלה אינן ניתנות לשליטה ישירה על ידי תוסף דפדפן, אך במהלך ההתקנה, Privacy Magic יעזור לכם למצוא את ההגדרות ולכבות אותן בעצמכם.

| :--- | :--- | :--- |
| סנכרון היסטוריה | כשאתם מחוברים ל-Chrome, הוא מסנכרן את היסטוריית הגלישה שלכם בין מכשירים. הוא גם שומר את אותם נתונים בשרתי Google. | Privacy Magic מנחה אתכם להגדרה שמשביתה סנכרון היסטוריה כדי לשמור על היסטוריית הגלישה שלכם פרטית. |
| מדדי חוויית משתמש | Chrome שולח בשקט מדדים על השימוש שלכם בדפדפן בחזרה לשרתי Google. | Privacy Magic עוזר לכם לחסום איסוף נתונים מוסתר זה. |
| איסוף נתונים לפי URL | עבור כל URL שאתם מבקרים בו, Chrome אוסף נתונים "אנונימיים" על הגלישה שלכם בדפים אלה ושולח אותם ל-Google. | Privacy Magic עוזר לכם להשבית הגדרה זו כדי למנוע שליחת הנתונים. |
