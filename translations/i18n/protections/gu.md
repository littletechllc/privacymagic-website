Privacy Magic એ Chrome માટેનું ઓપન-સોર્સ એક્સટેન્શન છે જે વેબ બ્રાઉઝ કરતી વખતે તમારી ગોપનીયતાનું વ્યાપક રક્ષણ કરે છે. બ્રાઉઝર ખૂબ લીકી હોય છે, તેથી Privacy Magic બહુવિધ સ્તરની સુરક્ષા પૂરી પાડે છે, જેમાં [જાહેરાતો અને ટ્રેકર્સ બ્લોક કરવા](#blocking-ads-and-trackers), [સિસ્ટમ માહિતીનું રક્ષણ](#protecting-system-information-fingerprinting), [ટ્રેકિંગ બ્રેડક્રમ્બ્સ દૂર કરવા](#removing-tracking-breadcrumbs), [વેબ લીક રોકવા](#stopping-web-leaks), [ગોપનીયતા સિગ્નલ મોકલવા](#privacy-signals), અને [બ્રાઉઝર સુરક્ષા લાગુ કરવી](#browser-protections) સામેલ છે.

## જાહેરાતો અને ટ્રેકર્સ બ્લોક કરવા {#blocking-ads-and-trackers}

સમગ્ર વેબ પર, જાહેરાતો, ટ્રેકિંગ સ્ક્રિપ્ટ્સ અને ટ્રેકિંગ પિક્સલ્સ તમારી સંમતિ વગર વિવિધ અદૃશ્ય પદ્ધતિઓથી તમને અનુસરે છે.

Privacy Magic લોકપ્રિય ફિલ્ટર યાદીઓ વાપરીને ઘણી જાહેરાતો અને ટ્રેકર્સને નેટવર્ક પર તમારા બ્રાઉઝર દ્વારા વિનંતી થવાથી બ્લોક કરે છે. ફિલ્ટર યાદીઓ તે ખાલી બૉક્સ પણ છુપાવે છે જે વેબ પેજ પર જાહેરાતો બ્લોક થાય ત્યારે રહી જાય છે. Privacy Magic આ ફિલ્ટર યાદીઓનું પિન કરેલું વર્ઝન વાપરે છે જેથી એક્સટેન્શનનું બ્લોકિંગ વર્તન સંપૂર્ણપણે પુનઃઉત્પાદનયોગ્ય અને દરેક વપરાશકર્તા માટે સમાન રહે.

| :--- | :--- |

| [EasyPrivacy](https://easylist.to/) | ટ્રેકર્સ, જેમાં ટ્રેકિંગ સ્ક્રિપ્ટ્સ, પિક્સલ્સ, વેબ બગ્સ અને અન્ય માહિતી એકત્ર કરનારા સામેલ છે. |

## સિસ્ટમ માહિતીનું રક્ષણ (ફિંગરપ્રિન્ટિંગ) {#protecting-system-information-fingerprinting}

પરંપરાગત રીતે, બ્રાઉઝર તમારા કમ્પ્યુટર વિશે ભરપૂર માહિતી કોઈપણ વેબસાઇટ અથવા ટ્રેકિંગ સ્ક્રિપ્ટને લીક કરે છે જે માંગે! અને ટ્રેકર્સ આ ડેટા એકત્ર કરીને વેબ બ્રાઉઝ કરતી વખતે તમને અનુસરે છે.

| ટાઇમિંગ | ઉચ્ચ રિઝોલ્યુશન ટાઇમિંગ API સ્ક્રિપ્ટ્સને બ્રાઉઝર વર્તનની ટાઇમિંગમાં સૂક્ષ્મ તફાવત માપીને તમારી સિસ્ટમનું લક્ષણ નિર્ધારિત કરવા દે છે. | Privacy Magic આ API દ્વારા આપેલા સમયને રાઉન્ડ કરે છે જેથી ટ્રેકિંગ સ્ક્રિપ્ટ્સ માટે તેનો ઉપયોગ કરીને બ્રાઉઝર અલગ પાડવું ઘણું મુશ્કેલ બને. |
| ટચ | Touch API લીક કરે છે કે તમારા ડિવાઇસમાં ટચ છે કે નહીં અને તે કેટલા ટચ પોઇન્ટને મંજૂરી આપે છે. | Privacy Magic આ માહિતીને વેબસાઇટ્સથી છુપાવે છે. |

## ટ્રેકિંગ બ્રેડક્રમ્બ્સ દૂર કરવા {#removing-tracking-breadcrumbs}

કેટલીક બ્રાઉઝર સુવિધાઓ તમારા બ્રાઉઝિંગ ઇતિહાસના ભાગો ("બ્રેડક્રમ્બ્સ") તમે મુલાકાત લો છો તે વિવિધ વેબસાઇટ્સ સાથે શેર કરવા માટે નબળી છે. Privacy Magic આ સુવિધાઓને મજબૂત બનાવે છે જેથી તે ઓછી લીકી હોય.

| બ્રેડક્રમ્બ | માનક વેબ બ્રાઉઝર | Privacy Magic |
| :--- | :--- | :--- |
| Cache Leaks | બ્રાઉઝર સ્થાનિક કૅશમાં ડેટા સંગ્રહે છે, જેથી તમે પેજ બીજી વાર જુઓ ત્યારે તે ડેટા ફરીથી લોડ કરવાની જરૂર ન પડે. કમનસીબે, તે કૅશ ક્યારેક લીકી હોય છે અને તમે મુલાકાત લો છો તે વેબસાઇટને તમારા બ્રાઉઝિંગ ઇતિહાસ વિશે કંઈક જાહેર કરે છે. | Privacy Magic નબળા કૅશ સાફ કરે છે જેથી આ લીક ન થઈ શકે. |
| Referrer Policy | પરંપરાગત રીતે, બ્રાઉઝર તમે મુલાકાત લો છો તે દરેક વેબ પેજને કહે છે કે તમે કયા વેબ પેજથી આવ્યા છો! | Privacy Magic રેફરરમાં ચોક્કસ પેજ (અથવા પાથ) કાઢી નાખે છે, અને વેબ સુસંગતતા માટે ફક્ત ડોમેન શેર કરવાની મંજૂરી આપે છે. |
| Tracking Parameters | ટ્રેકર્સ તમે મુલાકાત લો છો તે વેબ પેજના સરનામામાં વધારાના "ટ્રેકિંગ પેરામીટર્સ" ઉમેરી શકે છે, જેથી જાહેરાતકર્તાઓ તમે કોણ છો અથવા ક્યાં બ્રાઉઝ કર્યું છે તે ટ્રેક કરી શકે. | Privacy Magic વેબ સરનામાંમાંથી જાણીતા ટ્રેકિંગ પેરામીટર્સ કાઢી નાખે છે જેથી આ માહિતી તમે મુલાકાત લો છો તે વેબસાઇટ્સ સાથે શેર ન થાય. |
| Window Name | સામાન્ય રીતે, `window.name` JavaScript API જો તમે એક જ ટૅબમાં વેબસાઇટ્સ વચ્ચે નેવિગેટ કરો તો ડેટા લીક કરે છે. | Privacy Magic દરેક વેબસાઇટ માટે અલગ `window.name` લાગુ કરીને આ લીક અટકાવે છે. |

## વેબ લીક રોકવા {#stopping-web-leaks}

વેબ બ્રાઉઝર જટિલ પ્રાણી છે! ખાનગી માહિતીની લીક ઘણી અલગ બ્રાઉઝર સુવિધાઓમાંથી નીકળી શકે છે. Privacy Magicમાં અમારો અભિગમ છે કે જ્યાં પણ લીક મળે ત્યાં તેને બંધ કરવી.

| સુવિધા | માનક વેબ બ્રાઉઝર | Privacy Magic |
| :--- | :--- | :--- |
| Iframes | iframe એ "વેબ પેજની અંદર વેબ પેજ" છે. તમે મુલાકાત લો છો તે પેજની અંદરનું બૉક્સ, જ્યાં બીજું વેબ પેજ છુપાઈને સામાન્ય વેબ પેજ જેવી બધી ટ્રેકિંગ તકનીકો વાપરી શકે છે. | Privacy Magic વેબ પેજ પરના દરેક iframeમાં તેની બધી સુરક્ષા ઇન્જેક્ટ કરે છે, જેથી ટ્રેકર iframeમાં છુપાઈને તે સુરક્ષા બાયપાસ ન કરી શકે. |
| Service Workers | Service Workers એ બ્રાઉઝર સુવિધા છે જે તમે ઇન્ટરનેટ સાથે જોડાયેલા ન હો ત્યારે પણ બેકગ્રાઉન્ડમાં કોડ ચલાવવા દે છે. કમનસીબે, આ Service Workers સરળતાથી ખાનગી માહિતી લીક કરી શકે છે. | ખાનગી માહિતીની લીક રોકવા માટે Service workers સામાન્ય રીતે બધી સાઇટ્સ પર અક્ષમ હોય છે, જે અન્યથા પેચ કરી શકાતી નથી. |
| Shared Storage | Shared Storage એ બ્રાઉઝર સુવિધા છે જે તમારા બ્રાઉઝિંગ વિશેનો ડેટા એકત્રિત અને એકત્ર કરવા દે છે. જોકે તેને ગોપનીયતા-સંરક્ષક તરીકે દાવો કરાયો હતો, આ સુવિધાએ મજબૂત ગોપનીયતા ચિંતાઓ ઉભી કરી અને તે બ્રાઉઝરમાંથી દૂર થવાની છે. | Privacy Magic ખાતરી કરે છે કે Shared Storage બધી વેબસાઇટ્સ પર અક્ષમ છે. |
| Shared Workers | Shared Workers એ બેકગ્રાઉન્ડમાં ચાલતો કોડ છે જે વેબસાઇટ્સ વચ્ચે શેર થઈ શકે છે. | Privacy Magic કોઈપણ વેબસાઇટ દ્વારા લોડ થયેલા દરેક Shared Workerમાં તેની સુરક્ષા ઇન્જેક્ટ કરે છે. |
| Web Workers | Web Workers એ વેબ પેજ પર બેકગ્રાઉન્ડમાં ચાલતો કોડ છે. મુખ્ય પેજની સ્ક્રિપ્ટ્સની જેમ, web worker કોડ ખાનગી ડેટા લીક કરી શકે છે. | Privacy Magic પેજ પરના દરેક Web Workerમાં તેની સુરક્ષા ઇન્જેક્ટ કરે છે, જેથી ટ્રેકર્સ Web Workers વાપરીને તે સુરક્ષા બાયપાસ ન કરી શકે. |

## ગોપનીયતા સિગ્નલ {#privacy-signals}

અમે દરેક શક્ય રીતે તમારી ગોપનીયતા સુધારવામાં રસ ધરાવીએ છીએ. તેથી Privacy Magic તમે મુલાકાત લો છો તે વેબસાઇટ્સ પાસેથી ગોપનીયતા-મૈત્રીપૂર્ણ નીતિઓની માંગ કરતું સિગ્નલ મોકલે છે.

| સિગ્નલ | માનક વેબ બ્રાઉઝર | Privacy Magic |
| :--- | :--- | :--- |
| Global Privacy Control | Global Privacy Control એ સિગ્નલ છે જે તમે મુલાકાત લો છો તે વેબસાઇટ્સને મોકલી શકાય છે કે તમે તમારો ડેટા વેચવો કે શેર કરવો નથી માંગતા. કમનસીબે, મોટાભાગના વેબ બ્રાઉઝર ડિફોલ્ટ રીતે Global Privacy Control પસંદગી મોકલતા નથી. | Privacy Magic ખાતરી કરે છે કે તમારું બ્રાઉઝર દરેક વેબ પેજ અથવા એમ્બેડેડ રિસોર્સ પર દરેક વિનંતી સાથે Global Privacy Control હેડર મોકલે. તે દરેક પેજ અને iframeમાં JavaScript સિગ્નલ પણ ઇન્જેક્ટ કરે છે. |

## બ્રાઉઝર સુરક્ષા {#browser-protections}

બ્રાઉઝર ફક્ત વેબ પેજ રેન્ડર કરવામાં જ નહીં, પરંતુ પેરેંટ કંપની અથવા તૃતીય-પક્ષ જાહેરાત કંપનીઓને ડેટા મોકલવામાં પણ ખરાબ વર્તન કરે છે. Privacy Magic વિવિધ ખરાબ બ્રાઉઝર વર્તન અક્ષમ કરે છે જે અન્યથા તમારી ખાનગી માહિતી લીક કરત.

| સુવિધા | માનક વેબ બ્રાઉઝર | Privacy Magic |
| :--- | :--- | :--- |
| Hyperlink Auditing | માનક બ્રાઉઝરમાં એવી સુવિધા છે જે વેબસાઇટ્સને તમે ક્લિક કરો છો તે લિંક્સ સાથે ટ્રેકિંગ સર્વરને "પિંગ" કરવા દે છે. | Privacy Magic આ પિંગ અક્ષમ કરે છે. |
| Third-Party Cookies | બધામાં સૌથી પ્રખ્યાત ટ્રેકિંગ સુવિધા. Chrome તૃતીય-પક્ષ કુકીઝને મંજૂરી આપે છે જે તમને સાઇટથી સાઇટ સુધી ટ્રેક કરવા દે છે. | Privacy Magic ડિફોલ્ટ રીતે તૃતીય-પક્ષ કુકીઝ અક્ષમ કરે છે. |
| WebRTC non-proxied UDP | WebRTC એ વેબ બ્રાઉઝર ક્ષમતા છે જે તમને અન્ય વેબ વપરાશકર્તાઓ સાથે સીધો સંવાદ કરવા દે છે. કમનસીબે, જો તમે બ્રાઉઝર પ્રોક્સી વાપરતા હો, તો માનક Chrome-આધારિત બ્રાઉઝર પ્રોક્સીની બહાર WebRTC સંવાદ લીક કરે છે. | Privacy Magic WebRTC લીક બ્લોક કરે છે, છતાં જે વેબસાઇટ્સ તે વાપરે છે ત્યાં WebRTC કાર્ય કરવા દે છે. |

| Alternate Error Pages | ડિફોલ્ટ રીતે, ભૂલ થાય ત્યારે Chrome વૈકલ્પિક એરર પેજ બતાવે છે. આ પેજ બતાવવા માટે, તમે કયા પેજ મુલાકાત લો છો તે વિશેનો ડેટા Googleના સર્વર પર મોકલાય છે. | Privacy Magic આ વૈકલ્પિક એરર પેજ અક્ષમ કરે છે જેથી કોઈ ડેટા ન મોકલાય. |
| Safe Browsing Extended Reporting | Safe Browsing પેજ બ્લોક કરે ત્યારે, Chrome બ્લોક થયેલા પેજની સામગ્રી Googleના સર્વર પર મોકલી શકે છે. | Privacy Magic આ સુવિધા બ્લોક કરે છે, જેથી કોઈ ડેટા ન મોકલાય. |
| Search Suggest | ડિફોલ્ટ રીતે, Chrome તમે એડ્રેસ બારમાં જે ટાઇપ કરો છો તે ટાઇપ કરતી વખતે જ તમારા ડિફોલ્ટ સર્ચ એન્જિન (સામાન્ય રીતે Google search) પર મોકલે છે, ઑટો-સજેશન માટે. | Privacy Magic આ સતત મોનિટરિંગ બ્લોક કરે છે, જેથી તમે "enter" દબાવો ત્યારે જ Chrome તમારી સર્ચ મોકલે. |
| Spelling Service | Chrome "enhanced spell check" ઓફર કરે છે જે તમે ટાઇપ કરો છો તે Googleના સર્વર પર મોકલે છે. | Privacy Magic આ વિકલ્પ અક્ષમ કરે છે અને Chromeને ફક્ત સ્થાનિક "basic spell check" વાપરવાની મંજૂરી આપે છે. |

### એડ ટાર્ગેટિંગ API અક્ષમ કરવી {#disabling-ad-targeting-apis}

| :--- | :--- | :--- |
| Ad Measurement API | Ad Measurement API (અને સંબંધિત Private Aggregation API) તમારા બ્રાઉઝિંગ, તમે ક્લિક કરો છો તે જાહેરાતો અને અન્ય ખાનગી ડેટા જાહેરાત સર્વર પર મોકલે છે. | Privacy Magic તમારા ડેટાનું રક્ષણ કરવા આ API અક્ષમ કરે છે. |
| Protected Audience API | ડિફોલ્ટ રીતે, આ API Chrome દ્વારા જાહેરાતકર્તાઓ વતી તમારા ધ્યાન પર હરાજી ચલાવવા માટે ઉપલબ્ધ કરાય છે. | Privacy Magic આ API અક્ષમ કરે છે જેથી તમારો બ્રાઉઝિંગ ડેટા આ રીતે વપરાય નહીં. |
| Topics API | Chromeનું Topics API જાહેરાતકર્તાઓને એવા વિષયોની યાદી આપે છે જે કથિત રીતે તમને રસપ્રદ છે. | Privacy Magic તે ડેટા ખાનગી રાખવા Topics API અક્ષમ કરે છે. |

### લીકી Chrome સેટિંગ્સ અક્ષમ કરવી {#disabling-leaky-chrome-settings}

Chromeમાં કેટલીક સેટિંગ્સ છે જે તમારી ગોપનીયતાની વિરુદ્ધ છે: ખાસ કરીને, જે કાર્યક્ષમતા તમારી બ્રાઉઝિંગ આદતોનો ડેટા એકત્ર કરીને Googleના સર્વર પર મોકલે છે. આ સેટિંગ્સ સીધી બ્રાઉઝર એક્સટેન્શન દ્વારા નિયંત્રિત થઈ શકતી નથી, પરંતુ સેટઅપ દરમિયાન Privacy Magic તમને સેટિંગ્સ શોધીને જાતે બંધ કરવામાં મદદ કરશે.

| સેટિંગ | માનક વેબ બ્રાઉઝર | Privacy Magic |
| :--- | :--- | :--- |
| History syncing | જ્યારે તમે Chromeમાં સાઇન ઇન હો, ત્યારે તે ડિવાઇસ વચ્ચે તમારો બ્રાઉઝિંગ ઇતિહાસ સિંક કરે છે. તે એ જ ડેટા Google સર્વર પર પણ સાચવે છે. | Privacy Magic તમને તે સેટિંગ તરફ માર્ગદર્શન આપે છે જે હિસ્ટરી સિંકિંગ અક્ષમ કરીને તમારો બ્રાઉઝિંગ ઇતિહાસ ખાનગી રાખે છે. |
| User experience metrics | Chrome મૌન રીતે તમારા બ્રાઉઝર ઉપયોગના મેટ્રિક્સ Googleના સર્વર પર મોકલે છે. | Privacy Magic તમને આ છુપી ડેટા એકત્રીકરણ બ્લોક કરવામાં મદદ કરે છે. |
| Per-URL data collection | તમે મુલાકાત લો છો તે દરેક URL માટે, Chrome તે પેજ પર તમારા બ્રાઉઝિંગનો "અનોનિમાઇઝ્ડ" ડેટા એકત્ર કરીને Googleને મોકલે છે. | Privacy Magic તમને આ સેટિંગ અક્ષમ કરવામાં મદદ કરે છે જેથી ડેટા મોકલાય નહીં. |
