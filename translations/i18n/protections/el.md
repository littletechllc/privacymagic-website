Το Privacy Magic είναι μια επέκταση ανοιχτού κώδικα για το Chrome που προστατεύει ολοκληρωμένα το απόρρητό σας καθώς περιηγείστε στον ιστό. Οι περιηγητές «διαρρέουν» έντονα, γι' αυτό το Privacy Magic παρέχει πολλαπλά επίπεδα προστασίας, όπως [μπλοκάρισμα διαφημίσεων και ιχνηλατών](#blocking-ads-and-trackers), [προστασία πληροφοριών συστήματος](#protecting-system-information-fingerprinting), [αφαίρεση ιχνών παρακολούθησης](#removing-tracking-breadcrumbs), [διακοπή διαρροών ιστού](#stopping-web-leaks), [αποστολή σημάτων απορρήτου](#privacy-signals) και [εφαρμογή προστασιών περιηγητή](#browser-protections).

## Μπλοκάρισμα διαφημίσεων και ιχνηλατών {#blocking-ads-and-trackers}

Σε όλο τον ιστό, διαφημίσεις, σενάρια παρακολούθησης και pixel παρακολούθησης σας ακολουθούν χωρίς τη συγκατάθεσή σας χρησιμοποιώντας διάφορες αόρατες μεθόδους.

Το Privacy Magic χρησιμοποιεί δημοφιλείς λίστες φίλτρων για να εμποδίσει πολλά αιτήματα διαφημίσεων και ιχνηλατών από τον περιηγητή σας στο δίκτυο. Οι λίστες φίλτρων κρύβουν επίσης τα κενά πλαίσια που μένουν όταν μπλοκάρονται διαφημίσεις σε μια ιστοσελίδα. Το Privacy Magic χρησιμοποιεί καρφιτσωμένη έκδοση αυτών των λιστών φίλτρων ώστε η συμπεριφορά μπλοκαρίσματος της επέκτασης να είναι πλήρως αναπαραγώγιμη και ίδια για κάθε χρήστη.

| Λίστα φίλτρων | Στοιχεία που μπλοκάρονται |
| :--- | :--- |
| [EasyList](https://easylist.to/) | Διαφημίσεις, συμπεριλαμβανομένων banner, σεναρίων διαφημίσεων, εικόνων και διαφημίσεων βίντεο. |
| [EasyPrivacy](https://easylist.to/) | Ιχνηλάτες, συμπεριλαμβανομένων σεναρίων παρακολούθησης, pixel, web bugs και άλλων συλλεκτών πληροφοριών. |
| [Fanboy's Annoyance List](https://easylist.to/) | Ειδοποιήσεις cookie, γραφικά στοιχεία μέσων κοινωνικής δικτύωσης, αναδυόμενα μέσα στη σελίδα και άλλες οχλήσεις. |
| [small oisd blocklist](https://oisd.nl/) | Πρόσθετοι διαφημιστικοί τομείς. |

## Προστασία πληροφοριών συστήματος (δακτυλικό αποτύπωμα) {#protecting-system-information-fingerprinting}

Παραδοσιακά, οι περιηγητές διαρρέουν άφθονες πληροφορίες για τον υπολογιστή σας σε οποιαδήποτε ιστοσελίδα ή σενάριο παρακολούθησης το ζητήσει! Και οι ιχνηλάτες συγκεντρώνουν αυτά τα δεδομένα για να σας παρακολουθούν καθώς περιηγείστε στον ιστό.

| Αποτύπωμα | Τυπικοί περιηγητές ιστού | Privacy Magic |
| :--- | :--- | :--- |
| Ήχος | Η λειτουργικότητα επεξεργασίας ήχου των περιηγητών συνήθως διαρρέει πληροφορίες για την κάρτα ήχου σας. | Το Privacy Magic μειώνει τέτοιες διαρροές διαγράφοντας το λιγότερο σημαντικό bit από τα δεδομένα ήχου κάθε φορά που τα διαβάζει ένα σενάριο. Αυτή η διαγραφή δεν έχει ακουστές επιπτώσεις. |
| Μπαταρία | Οι περιηγητές συνήθως ενημερώνουν οποιαδήποτε ιστοσελίδα το ζητήσει για το επίπεδο μπαταρίας, αν η συσκευή είναι συνδεδεμένη σε τροφοδοσία και μια εκτίμηση του χρόνου που απομένει πριν αδειάσει η μπαταρία. | Το Privacy Magic σταματά αυτή τη διαρροή προσομοιώνοντας μπαταρία πάντα στο 100% και τροφοδοσία πάντα συνδεδεμένη. |
| Περιηγητής | Μια ιστοσελίδα μπορεί να ανακρίνει τον περιηγητή σας για λεπτομερείς πληροφορίες για το λειτουργικό σύστημα στο οποίο τρέχει. | Το Privacy Magic παραποιεί το `navigator.platform` σε μία τιμή για κάθε διαφορετικό λειτουργικό σύστημα. |
| Συσκευή | Οι περιηγητές ενημερώνουν οποιαδήποτε ιστοσελίδα το ζητήσει αν χρησιμοποιείτε πτυσσόμενη συσκευή. | Το Privacy Magic αναφέρει πάντα ότι η συσκευή σας δεν είναι πτυσσόμενη. |
| Δίσκος | Οι περιηγητές συνήθως διαρρέουν πόσος χώρος δίσκου είναι διαθέσιμος στην ιστοσελίδα και πόσο χρησιμοποιεί, κάτι που μπορεί να αποκαλύψει τον συνολικό χώρο δίσκου στον υπολογιστή σας και τον τρόπο αποθήκευσης των δεδομένων. | Το Privacy Magic παραποιεί αυτές τις τιμές ώστε να είναι ίδιες για όλους. |
| Οθόνη | Παραδοσιακά οι περιηγητές διαρρέουν ρυθμίσεις οθόνης, συμπεριλαμβανομένου αν το σύστημά σας έχει οριστεί σε «προτίμηση μειωμένης κίνησης». | Το Privacy Magic αποτρέπει αυτή τη διαρροή. |
| Γραμματοσειρές | Οι τυπικοί περιηγητές διαρρέουν ποιες προσαρμοσμένες γραμματοσειρές έχετε εγκαταστήσει στο σύστημά σας, κάνοντας ενδεχομένως το αποτύπωμά σας πολύ μοναδικό. | Το Privacy Magic κρύβει τις προσαρμοσμένες γραμματοσειρές του συστήματός σας από όλα τα σενάρια. Οι ιστοσελίδες μπορούν να συνεχίσουν να χρησιμοποιούν τυπικές γραμματοσειρές συστήματος και γραμματοσειρές ιστού που κατεβάζονται. |
| Γραφικά | Το Canvas και το WebGL είναι δύο βασικοί φορείς δακτυλικού αποτυπώματος που διαρρέουν το είδος της GPU (τσιπ γραφικών) που χρησιμοποιεί ο υπολογιστής σας. | Το Privacy Magic χρησιμοποιεί προηγμένες τεχνικές για να κρύψει το τσιπ γραφικών επιτρέποντάς σας να συνεχίσετε να παίζετε παιχνίδια και να χρησιμοποιείτε ιστοσελίδες με έντονη χρήση γραφικών. |
| Πληκτρολόγιο | Από προεπιλογή, οι περιηγητές διαρρέουν τη διάταξη πληκτρολογίου που χρησιμοποιείτε σε οποιαδήποτε ιστοσελίδα το ζητήσει. | Το Privacy Magic εμποδίζει την αποκάλυψη της διάταξης πληκτρολογίου σε σενάρια ιστοσελίδων. |
| Γλώσσα | Συνήθως οι περιηγητές διαρρέουν μια λίστα γλωσσών που έχετε εγκρίνει. Αν και είναι σημαντικό να μπορείτε να ορίσετε ποια γλώσσα προτιμάτε για τις ιστοσελίδες που επισκέπτεστε, οι περιηγητές συνήθως αποκαλύπτουν λίστα προτιμώμενων γλωσσών του χρήστη, κάτι που μπορεί να είναι υπερβολικά αποκαλυπτικό. | Το Privacy Magic επιτρέπει να περνά μόνο μία γλώσσα στις ιστοσελίδες που επισκέπτεστε. |
| Μαθηματικά | Τα σενάρια παρακολούθησης σε ιστοσελίδες μπορούν να χρησιμοποιήσουν ιδιότυπη συμπεριφορά μαθηματικών συναρτήσεων, όπως συνημίτονο ή υπερβολική εφαπτομένη, στη συσκευή σας για να σας ξεχωρίσουν από άλλους χρήστες. | Το Privacy Magic διορθώνει τις συναρτήσεις Math της JavaScript ώστε να συμπεριφέρονται πανομοιότυπα σε όλες τις πλατφόρμες. |
| Μνήμη | Οι ιστοσελίδες μπορούν να μάθουν από τους περισσότερους περιηγητές πόση αχρησιμοποίητη μνήμη υπάρχει στον υπολογιστή σας. | Το Privacy Magic κρύβει την ποσότητα διαθέσιμης μνήμης του συστήματός σας από ιστοσελίδες και ιχνηλάτες. |
| Δίκτυο | Οι περιηγητές κανονικά διαρρέουν λεπτομέρειες για το είδος της δικτυακής σύνδεσης που έχετε. | Το Privacy Magic αποτρέπει τη διαρροή αυτών των λεπτομερειών καθιστώντας τις ομοιογενείς για όλους τους χρήστες. |
| Επεξεργαστής | Οι περιηγητές είναι σχεδιασμένοι να αναφέρουν τον αριθμό πυρήνων του επεξεργαστή του υπολογιστή σας. | Το Privacy Magic προσποιείται ότι όλοι έχουν ακριβώς `4`. |
| Οθόνη (διαστάσεις) | Οι περιηγητές διαρρέουν τις διαστάσεις της οθόνης σας σε οποιαδήποτε ιστοσελίδα το ζητήσει, ανεξάρτητα από το μέγεθος του παραθύρου του περιηγητή. | Το Privacy Magic κρύβει το πραγματικό μέγεθος οθόνης. |
| Ζώνη ώρας | Οι περιηγητές διαρρέουν την κατά προσέγγιση τοποθεσία σας όταν τα σενάρια ζητούν τη ζώνη ώρας σας. Για παράδειγμα, αν είστε σε Κεντρική Ευρωπαϊκή Ώρα, ο περιηγητής θα παρέχει αναγνωριστικό ζώνης ώρας που υποδεικνύει αν είστε στο Παρίσι, το Βερολίνο, το Λουξεμβούργο ή σε μία από δεκάδες άλλες πόλεις. | Το Privacy Magic ενοποιεί τις ζώνες ώρας ώστε κάθε μετατόπιση ζώνης ώρας να έχει μία αντιπροσωπευτική ζώνη. Έτσι ο περιηγητής δεν διαρρέει περιττές πληροφορίες για την τοποθεσία σας στον πλανήτη. |
| Χρονισμός | Τα API υψηλής ανάλυσης χρονισμού επιτρέπουν στα σενάρια να χαρακτηρίζουν το σύστημά σας μετρώντας μικροσκοπικές διαφορές στον χρονισμό συμπεριφορών του περιηγητή. | Το Privacy Magic στρογγυλοποιεί τους χρόνους που παρέχουν αυτά τα API ώστε να είναι πολύ δυσκολότερο για τα σενάρια παρακολούθησης να τα χρησιμοποιήσουν για να διακρίνουν περιηγητές. |
| Αφή | Το Touch API διαρρέει αν η συσκευή σας έχει αφή και πόσες σημειακές επαφές επιτρέπει. | Το Privacy Magic κρύβει αυτές τις πληροφορίες από τις ιστοσελίδες. |

## Αφαίρεση ιχνών παρακολούθησης {#removing-tracking-breadcrumbs}

Ορισμένες δυνατότητες περιηγητή είναι ευάλωτες στη χρήση για κοινή χρήση τμημάτων του ιστορικού περιήγησής σας («ψίχουλα») σε διαφορετικές ιστοσελίδες που επισκέπτεστε. Το Privacy Magic ενισχύει αυτές τις δυνατότητες ώστε να διαρρέουν λιγότερο.

| Ίχνος | Τυπικοί περιηγητές ιστού | Privacy Magic |
| :--- | :--- | :--- |
| Διαρροές προσωρινής μνήμης | Οι περιηγητές αποθηκεύουν δεδομένα σε τοπικές προσωρινές μνήμες, ώστε όταν επισκέπτεστε μια σελίδα ή την προβάλλετε δεύτερη φορά, τα δεδομένα να μην χρειάζεται να φορτωθούν ξανά. Δυστυχώς, αυτές οι μνήμες μερικές φορές διαρρέουν και αποκαλύπτουν κάτι για το ιστορικό περιήγησής σας σε μια ιστοσελίδα που επισκέπτεστε. | Το Privacy Magic καθαρίζει τις ευάλωτες προσωρινές μνήμες ώστε αυτές οι διαρροές να μην μπορούν να συμβούν. |
| Πολιτική παραπομπής | Παραδοσιακά, οι περιηγητές ενημερώνουν κάθε ιστοσελίδα που επισκέπτεστε από ποια ιστοσελίδα ήρθατε! | Το Privacy Magic διαγράφει την ακριβή σελίδα (ή διαδρομή) στον παραπέμποντα και, για συμβατότητα ιστού, επιτρέπει μόνο την κοινή χρήση του τομέα. |
| Παράμετροι παρακολούθησης | Οι ιχνηλάτες μπορούν να προσθέσουν επιπλέον «παραμέτρους παρακολούθησης» στις διευθύνσεις των ιστοσελίδων που επισκέπτεστε, ώστε οι διαφημιστές να παρακολουθούν ποιος είστε ή πού έχετε περιηγηθεί. | Το Privacy Magic διαγράφει γνωστές παραμέτρους παρακολούθησης από διευθύνσεις ιστού ώστε αυτές οι πληροφορίες να μην κοινοποιούνται στις ιστοσελίδες που επισκέπτεστε. |
| Όνομα παραθύρου | Κανονικά, το JavaScript API `window.name` διαρρέει δεδομένα αν πλοηγηθείτε μεταξύ ιστοσελίδων στην ίδια καρτέλα. | Το Privacy Magic αποτρέπει αυτή τη διαρροή επιβάλλοντας ξεχωριστό `window.name` για κάθε ιστοσελίδα. |

## Διακοπή διαρροών ιστού {#stopping-web-leaks}

Οι περιηγητές ιστού είναι περίπλοκα πλάσματα! Διαρροές ιδιωτικών πληροφοριών μπορούν να προκύψουν από πολλές διαφορετικές δυνατότητες περιηγητή. Η προσέγγισή μας στο Privacy Magic είναι να κλείνουμε διαρροές όπου κι αν εντοπίζονται.

| Δυνατότητα | Τυπικοί περιηγητές ιστού | Privacy Magic |
| :--- | :--- | :--- |
| Iframes | Ένα iframe είναι μια «ιστοσελίδα μέσα σε ιστοσελίδα». Είναι ένα πλαίσιο μέσα στη σελίδα που επισκέπτεστε, όπου μια δεύτερη ιστοσελίδα μπορεί να κρυφτεί και να χρησιμοποιήσει όλες τις ίδιες τεχνικές παρακολούθησης που μπορεί να χρησιμοποιήσει μια κανονική ιστοσελίδα. | Το Privacy Magic εγχέει όλες τις προστασίες του σε κάθε iframe μιας ιστοσελίδας, για να διασφαλίσει ότι ένας ιχνηλάτης δεν μπορεί να παρακάμψει αυτές τις προστασίες κρυμμένος μέσα σε iframe. |
| Service Workers | Οι Service Workers είναι δυνατότητα περιηγητή που επιτρέπει την εκτέλεση κώδικα στο παρασκήνιο ακόμη και όταν δεν είστε συνδεδεμένοι στο διαδίκτυο. Δυστυχώς, αυτοί οι Service Workers μπορούν εύκολα να διαρρεύσουν ιδιωτικές πληροφορίες. | Οι Service Workers γενικά απενεργοποιούνται σε όλους τους ιστότοπους, για να αποτραπούν διαρροές ιδιωτικών πληροφοριών που δεν μπορούν να επιδιορθωθούν αλλιώς. |
| Shared Storage | Το Shared Storage είναι δυνατότητα περιηγητή που επιτρέπει τη συγκέντρωση και συλλογή δεδομένων για την περιήγησή σας. Αν και παρουσιάστηκε ως διατηρητική απορρήτου, αυτή η δυνατότητα προκάλεσε ισχυρές ανησυχίες απορρήτου και πρόκειται να αφαιρεθεί από τους περιηγητές. | Το Privacy Magic διασφαλίζει ότι το Shared Storage είναι απενεργοποιημένο σε όλους τους ιστότοπους. |
| Shared Workers | Οι Shared Workers είναι κώδικας που τρέχει στο παρασκήνιο και μπορεί να κοινοποιείται μεταξύ ιστοσελίδων. | Το Privacy Magic εγχέει τις προστασίες του σε κάθε Shared Worker που φορτώνεται από οποιαδήποτε ιστοσελίδα. |
| Web Workers | Οι Web Workers είναι κώδικας που τρέχει στο παρασκήνιο σε μια ιστοσελίδα. Όπως τα σενάρια της κύριας σελίδας, ο κώδικας web worker μπορεί να διαρρεύσει ιδιωτικά δεδομένα. | Το Privacy Magic εγχέει τις προστασίες του σε κάθε Web Worker μιας σελίδας, για να διασφαλίσει ότι οι ιχνηλάτες δεν μπορούν να χρησιμοποιήσουν Web Workers για να παρακάμψουν αυτές τις προστασίες. |

## Σήματα απορρήτου {#privacy-signals}

Ενδιαφερόμαστε να βελτιώσουμε το απόρρητό σας με κάθε δυνατό τρόπο. Έτσι το Privacy Magic στέλνει σήμα για να απαιτήσει πολιτικές υπέρ του απορρήτου από τις ιστοσελίδες που επισκέπτεστε.

| Σήμα | Τυπικοί περιηγητές ιστού | Privacy Magic |
| :--- | :--- | :--- |
| Global Privacy Control | Το Global Privacy Control είναι σήμα που μπορεί να σταλεί στις ιστοσελίδες που επισκέπτεστε για να υποδείξει ότι δεν θέλετε τα δεδομένα σας να πωληθούν ή να κοινοποιηθούν. Δυστυχώς, οι περισσότεροι περιηγητές δεν στέλνουν την προτίμηση Global Privacy Control από προεπιλογή. | Το Privacy Magic διασφαλίζει ότι ο περιηγητής σας στέλνει την κεφαλίδα Global Privacy Control με κάθε αίτημα σε κάθε ιστοσελίδα ή ενσωματωμένο πόρο. Εγχέει επίσης σήμα JavaScript σε κάθε σελίδα και iframe. |

## Προστασίες περιηγητή {#browser-protections}

Οι περιηγητές συμπεριφέρονται άσχημα όχι μόνο στον τρόπο που αποδίδουν ιστοσελίδες, αλλά και στον τρόπο που στέλνουν δεδομένα στη μητρική εταιρεία ή σε τρίτες διαφημιστικές εταιρείες. Το Privacy Magic απενεργοποιεί διάφορες κακές συμπεριφορές περιηγητή που διαφορετικά θα διέρρεαν τις ιδιωτικές σας πληροφορίες.

### Απενεργοποίηση διαρρεουσών δυνατοτήτων ιστού {#disabling-leaky-web-features}

| Δυνατότητα | Τυπικοί περιηγητές ιστού | Privacy Magic |
| :--- | :--- | :--- |
| Έλεγχος υπερσυνδέσμων | Οι τυπικοί περιηγητές έχουν δυνατότητα που επιτρέπει στις ιστοσελίδες να «στέλνουν ping» σε διακομιστή παρακολούθησης με τους συνδέσμους που κάνετε κλικ. | Το Privacy Magic απενεργοποιεί αυτό το ping. |
| Cookie τρίτων | Η πιο διάσημη δυνατότητα παρακολούθησης όλων. Το Chrome επιτρέπει cookie τρίτων που σας επιτρέπουν να παρακολουθείστε από ιστότοπο σε ιστότοπο. | Το Privacy Magic απενεργοποιεί τα cookie τρίτων από προεπιλογή. |
| WebRTC μη-προξενευμένο UDP | Το WebRTC είναι δυνατότητα περιηγητή που σας επιτρέπει να επικοινωνείτε απευθείας με άλλους χρήστες ιστού. Δυστυχώς, αν χρησιμοποιείτε διαμεσολαβητή περιηγητή, οι τυπικοί περιηγητές βασισμένοι στο Chrome διαρρέουν επικοινωνίες WebRTC εκτός του διαμεσολαβητή. | Το Privacy Magic μπλοκάρει τις διαρροές WebRTC, επιτρέποντας παράλληλα στο WebRTC να λειτουργεί στις ιστοσελίδες που το χρησιμοποιούν. |

### Απενεργοποίηση παρεμβατικών υπηρεσιών cloud {#disabling-invasive-cloud-services}

| Υπηρεσία | Τυπικοί περιηγητές ιστού | Privacy Magic |
| :--- | :--- | :--- |
| Εναλλακτικές σελίδες σφάλματος | Από προεπιλογή, το Chrome εμφανίζει εναλλακτικές σελίδες σφάλματος όταν συμβαίνει σφάλμα. Για να εμφανιστούν αυτές οι σελίδες, δεδομένα για τις σελίδες που επισκέπτεστε αποστέλλονται στους διακομιστές της Google. | Το Privacy Magic απενεργοποιεί αυτές τις εναλλακτικές σελίδες σφάλματος ώστε να μην αποστέλλονται δεδομένα. |
| Safe Browsing Extended Reporting | Όταν το Safe Browsing μπλοκάρει μια σελίδα, το Chrome μπορεί να στείλει το περιεχόμενο μιας μπλοκαρισμένης σελίδας στους διακομιστές της Google. | Το Privacy Magic μπλοκάρει αυτή τη δυνατότητα, ώστε να μην αποστέλλονται δεδομένα. |
| Προτάσεις αναζήτησης | Από προεπιλογή, το Chrome στέλνει οτιδήποτε πληκτρολογείτε στη γραμμή διευθύνσεων στη μηχανή αναζήτησης προεπιλογής σας (τυπικά αναζήτηση Google) ενώ πληκτρολογείτε, για αυτόματες προτάσεις. | Το Privacy Magic μπλοκάρει αυτή τη συνεχή παρακολούθηση, ώστε το Chrome να στέλνει την αναζήτησή σας μόνο όταν πατήσετε «enter». |
| Υπηρεσία ορθογραφίας | Το Chrome προσφέρει «βελτιωμένο ορθογραφικό έλεγχο» που στέλνει ό,τι πληκτρολογείτε στους διακομιστές της Google. | Το Privacy Magic απενεργοποιεί αυτή την επιλογή και επιτρέπει στο Chrome να χρησιμοποιεί μόνο τον τοπικό «βασικό ορθογραφικό έλεγχο». |

### Απενεργοποίηση API στόχευσης διαφημίσεων {#disabling-ad-targeting-apis}

| API | Τυπικοί περιηγητές ιστού | Privacy Magic |

### Απενεργοποίηση διαρρεουσών ρυθμίσεων Chrome {#disabling-leaky-chrome-settings}

Το Chrome περιέχει ορισμένες ρυθμίσεις που είναι αντίθετες με το απόρρητό σας: συγκεκριμένα, λειτουργικότητα που συλλέγει δεδομένα για τις συνήθειες περιήγησής σας και τα στέλνει στους διακομιστές της Google. Αυτές οι ρυθμίσεις δεν μπορούν να ελεγχθούν απευθείας από επέκταση περιηγητή, αλλά κατά τη ρύθμιση το Privacy Magic θα σας βοηθήσει να βρείτε τις ρυθμίσεις και να τις απενεργοποιήσετε μόνοι σας.

| Ρύθμιση | Τυπικοί περιηγητές ιστού | Privacy Magic |
| :--- | :--- | :--- |
| Συγχρονισμός ιστορικού | Όταν είστε συνδεδεμένοι στο Chrome, συγχρονίζει το ιστορικό περιήγησής σας μεταξύ συσκευών. Αποθηκεύει επίσης τα ίδια δεδομένα στους διακομιστές της Google. | Το Privacy Magic σας καθοδηγεί στη ρύθμιση που απενεργοποιεί τον συγχρονισμό ιστορικού για να κρατήσει ιδιωτικό το ιστορικό περιήγησής σας. |
| Μετρικές εμπειρίας χρήστη | Το Chrome στέλνει αθόρυβα μετρικές για τη χρήση του περιηγητή σας πίσω στους διακομιστές της Google. | Το Privacy Magic σας βοηθά να μπλοκάρετε αυτή την κρυφή συλλογή δεδομένων. |
| Συλλογή δεδομένων ανά URL | Για κάθε URL που επισκέπτεστε, το Chrome συλλέγει «ανωνυμοποιημένα» δεδομένα για την περιήγησή σας σε αυτές τις σελίδες και τα στέλνει στην Google. | Το Privacy Magic σας βοηθά να απενεργοποιήσετε αυτή τη ρύθμιση για να αποτρέψετε την αποστολή των δεδομένων. |
