Privacy Magic เป็นส่วนขยายโอเพนซอร์สสำหรับ Chrome ที่ปกป้องความเป็นส่วนตัวของคุณอย่างครอบคลุมขณะท่องเว็บ เบราว์เซอร์รั่วข้อมูลได้ง่ายมาก ดังนั้น Privacy Magic จึงมีชั้นการป้องกันหลายชั้น รวมถึง [การบล็อกโฆษณาและตัวติดตาม](#blocking-ads-and-trackers), [การปกป้องข้อมูลระบบ](#protecting-system-information-fingerprinting), [การลบร่องรอยการติดตาม](#removing-tracking-breadcrumbs), [การหยุดการรั่วไหลบนเว็บ](#stopping-web-leaks), [การส่งสัญญาณความเป็นส่วนตัว](#privacy-signals) และ [การบังคับใช้การป้องกันของเบราว์เซอร์](#browser-protections)

## การบล็อกโฆษณาและตัวติดตาม {#blocking-ads-and-trackers}

ทั่วทั้งเว็บ โฆษณา สคริปต์ติดตาม และพิกเซลติดตามกำลังตามคุณไปโดยไม่ได้รับความยินยอม โดยใช้วิธีการที่มองไม่เห็นหลากหลายรูปแบบ

Privacy Magic ใช้รายการตัวกรองยอดนิยมเพื่อบล็อกโฆษณาและตัวติดตามจำนวนมากไม่ให้เบราว์เซอร์ของคุณร้องขอผ่านเครือข่าย รายการตัวกรองยังซ่อนกล่องว่างที่เหลือเมื่อโฆษณาถูกบล็อกบนหน้าเว็บด้วย Privacy Magic ใช้เวอร์ชันที่ตรึงไว้ของรายการตัวกรองเหล่านี้ เพื่อให้พฤติกรรมการบล็อกของส่วนขยายสามารถทำซ้ำได้เต็มที่และเหมือนกันสำหรับผู้ใช้ทุกคน

| รายการตัวกรอง | รายการที่ถูกบล็อก |
| :--- | :--- |
| [EasyList](https://easylist.to/) | โฆษณา รวมถึงแบนเนอร์ สคริปต์โฆษณา รูปภาพ และโฆษณาวิดีโอ |
| [EasyPrivacy](https://easylist.to/) | ตัวติดตาม รวมถึงสคริปต์ติดตาม พิกเซล เว็บบัก และตัวเก็บข้อมูลอื่นๆ |
| [Fanboy's Annoyance List](https://easylist.to/) | ประกาศคุกกี้ วิดเจ็ตโซเชียลมีเดีย ป๊อปอัปในหน้า และสิ่งรบกวนอื่นๆ |
| [small oisd blocklist](https://oisd.nl/) | โดเมนโฆษณาเพิ่มเติม |

## การปกป้องข้อมูลระบบ (ลายนิ้วมือ) {#protecting-system-information-fingerprinting}

โดยทั่วไป เบราว์เซอร์จะรั่วข้อมูลจำนวนมากเกี่ยวกับคอมพิวเตอร์ของคุณไปยังเว็บไซต์หรือสคริปต์ติดตามใดๆ ที่ขอ! และตัวติดตามรวบรวมข้อมูลนี้เพื่อติดตามคุณขณะท่องเว็บ

| ลายนิ้วมือ | เว็บเบราว์เซอร์มาตรฐาน | Privacy Magic |
| :--- | :--- | :--- |
| Audio | ฟังก์ชันประมวลผลเสียงของเบราว์เซอร์มักรั่วข้อมูลเกี่ยวกับการ์ดเสียงของคุณ | Privacy Magic ลดการรั่วไหลดังกล่าวโดยลบบิตที่มีนัยสำคัญน้อยที่สุดจากข้อมูลเสียงทุกครั้งที่สคริปต์อ่าน การลบนี้ไม่มีผลต่อการได้ยิน |
| Battery | โดยทั่วไปเบราว์เซอร์จะบอกเว็บไซต์ใดๆ ที่ถามว่าระดับแบตเตอรี่ของคุณอยู่ที่เท่าใด อุปกรณ์เสียบปลั๊กอยู่หรือไม่ และประมาณการว่าแบตเตอรี่จะหมดในอีกกี่นาที | Privacy Magic หยุดการรั่วไหลนี้โดยจำลองแบตเตอรี่ที่อยู่ที่ 100% เสมอ และแหล่งจ่ายไฟที่เสียบปลั๊กอยู่เสมอ |
| Browser | หน้าเว็บสามารถสอบถามเบราว์เซอร์ของคุณเพื่อรับข้อมูลโดยละเอียดเกี่ยวกับระบบปฏิบัติการที่กำลังทำงานอยู่ | Privacy Magic ปลอม `navigator.platform` ให้เป็นค่าเดียวสำหรับแต่ละระบบปฏิบัติการที่ต่างกัน |
| Device | เบราว์เซอร์จะบอกเว็บไซต์ใดๆ ที่ถามว่าคุณใช้หน้าจอพับได้หรือไม่ | Privacy Magic รายงานเสมอว่าอุปกรณ์ของคุณไม่ใช่แบบพับได้ |
| Disk | โดยทั่วไปเบราว์เซอร์จะรั่วปริมาณพื้นที่ดิสก์ที่เว็บไซต์ใช้ได้ และว่าเว็บไซต์นั้นใช้อยู่เท่าใด ซึ่งอาจเปิดเผยพื้นที่ดิสก์ทั้งหมดบนคอมพิวเตอร์และวิธีจัดเก็บข้อมูล | Privacy Magic ปลอมค่าเหล่านี้ให้เหมือนกันสำหรับทุกคน |
| Display | ตามธรรมเนียม เบราว์เซอร์จะรั่วการตั้งค่าจอแสดงผล รวมถึงว่าระบบของคุณตั้งค่าเป็น "prefer reduced motion" หรือไม่ | Privacy Magic ป้องกันการรั่วไหลนี้ |
| Fonts | เว็บเบราว์เซอร์มาตรฐานรั่วว่าคุณติดตั้งแบบอักษรกำหนดเองอะไรบนระบบ ซึ่งอาจทำให้ลายนิ้วมือของคุณเป็นเอกลักษณ์มาก | Privacy Magic ซ่อนแบบอักษรกำหนดเองที่ติดตั้งบนระบบจากสคริปต์ทั้งหมด หน้าเว็บยังใช้แบบอักษรระบบมาตรฐานและเว็บฟอนต์ที่ดาวน์โหลดได้ตามปกติ |
| Graphics | Canvas และ WebGL เป็นเวกเตอร์ลายนิ้วมือสำคัญสองอย่างที่รั่วว่าคอมพิวเตอร์ของคุณใช้ GPU (ชิปกราฟิก) ชนิดใด | Privacy Magic ใช้เทคนิคขั้นสูงเพื่อซ่อนชิปกราฟิก ในขณะที่ยังให้คุณเล่นเกมและใช้เว็บไซต์ที่ใช้กราฟิกหนักได้ต่อ |
| Keyboard | โดยค่าเริ่มต้น เบราว์เซอร์จะรั่วรูปแบบแป้นพิมพ์ที่คุณใช้ไปยังเว็บไซต์ใดๆ ที่ถาม | Privacy Magic บล็อกไม่ให้สคริปต์เว็บไซต์รู้รูปแบบแป้นพิมพ์ของคุณ |
| Language | โดยทั่วไป เบราว์เซอร์จะรั่วรายการภาษาที่คุณอนุมัติ แม้ว่าการระบุภาษาที่ต้องการสำหรับเว็บไซต์ที่เยี่ยมชมจะสำคัญ แต่เบราว์เซอร์มักเปิดเผยรายการภาษาที่ผู้ใช้ชอบ ซึ่งอาจเปิดเผยมากเกินไป | Privacy Magic อนุญาตให้ส่งภาษาเพียงภาษาเดียวไปยังเว็บไซต์ที่คุณเยี่ยมชม |
| Math | สคริปต์ติดตามในหน้าเว็บสามารถใช้พฤติกรรมเฉพาะของฟังก์ชัน Math เช่น โคไซน์หรือไฮเพอร์โบลิกแทนเจนต์ บนอุปกรณ์ของคุณเพื่อแยกคุณจากผู้ใช้อื่น | Privacy Magic แพตช์ฟังก์ชัน JavaScript Math ให้ทำงานเหมือนกันบนทุกแพลตฟอร์ม |
| Memory | เว็บไซต์สามารถรู้จากเบราว์เซอร์ส่วนใหญ่ได้ว่ามีหน่วยความจำที่ยังไม่ใช้งานบนคอมพิวเตอร์ของคุณเท่าใด | Privacy Magic ซ่อนปริมาณหน่วยความจำที่มีบนระบบจากหน้าเว็บและตัวติดตาม |
| Network | โดยปกติเบราว์เซอร์จะรั่วรายละเอียดเกี่ยวกับชนิดการเชื่อมต่อเครือข่ายที่คุณมี | Privacy Magic ป้องกันไม่ให้รายละเอียดเหล่านี้รั่วโดยทำให้เหมือนกันในหมู่ผู้ใช้ทุกคน |
| Processor | เบราว์เซอร์ออกแบบมาให้รายงานจำนวนคอร์บนโปรเซสเซอร์ของคอมพิวเตอร์คุณ | Privacy Magic แสร้งว่าทุกคนมีพอดี `4` |
| Screen | เบราว์เซอร์จะรั่วขนาดหน้าจอของคุณไปยังเว็บไซต์ใดๆ ที่ถาม โดยไม่คำนึงว่าหน้าต่างเบราว์เซอร์ใหญ่แค่ไหน | Privacy Magic ซ่อนขนาดหน้าจอจริง |
| Time Zone | เบราว์เซอร์จะรั่วตำแหน่งโดยประมาณของคุณเมื่อสคริปต์ขอโซนเวลา ตัวอย่างเช่น หากคุณอยู่ในเวลายุโรปกลาง เบราว์เซอร์จะให้ตัวระบุโซนเวลาที่บ่งชี้ว่าคุณอยู่ในปารีส เบอร์ลิน ลักเซมเบิร์ก หรือเมืองใดเมืองหนึ่งในอีกหลายสิบเมือง | Privacy Magic รวมโซนเวลาให้ทุกออฟเซ็ตมีตัวแทนโซนเวลาเพียงหนึ่งตัว ด้วยวิธีนี้เบราว์เซอร์จะไม่รั่วข้อมูลที่ไม่จำเป็นเกี่ยวกับตำแหน่งของคุณบนโลก |
| Timing | API วัดเวลาความละเอียดสูงช่วยให้สคริปต์ระบุลักษณะระบบของคุณโดยวัดความต่างเล็กน้อยในจังหวะพฤติกรรมของเบราว์เซอร์ | Privacy Magic ปัดเศษเวลาที่ API เหล่านี้ให้ เพื่อให้สคริปต์ติดตามแยกแยะเบราว์เซอร์ได้ยากขึ้นมาก |
| Touch | Touch API รั่วว่าอุปกรณ์ของคุณมีการสัมผัสหรือไม่ และอนุญาตกี่จุดสัมผัส | Privacy Magic ซ่อนข้อมูลนี้จากเว็บไซต์ |

## การลบร่องรอยการติดตาม {#removing-tracking-breadcrumbs}

ฟีเจอร์บางอย่างของเบราว์เซอร์เปราะบางต่อการถูกใช้เพื่อแชร์ส่วนของประวัติการท่องเว็บของคุณ ("ร่องรอย") ไปยังเว็บไซต์ต่างๆ ที่คุณเยี่ยมชม Privacy Magic ทำให้ฟีเจอร์เหล่านี้แน่นหนาขึ้นเพื่อลดการรั่วไหล

| ร่องรอย | เว็บเบราว์เซอร์มาตรฐาน | Privacy Magic |
| :--- | :--- | :--- |
| Cache Leaks | เบราว์เซอร์เก็บข้อมูลในแคชภายในเครื่อง เพื่อว่าเมื่อคุณเยี่ยมชมหน้าหรือดูครั้งที่สอง จะไม่ต้องโหลดข้อมูลนั้นซ้ำ น่าเสียดายที่แคชเหล่านั้นบางครั้งรั่วและเปิดเผยบางอย่างเกี่ยวกับประวัติการท่องเว็บของคุณให้เว็บไซต์ที่คุณเยี่ยมชมรู้ | Privacy Magic ล้างแคชที่เปราะบางเพื่อไม่ให้เกิดการรั่วไหลเหล่านี้ |
| Referrer Policy | ตามธรรมเนียม เบราว์เซอร์จะบอกแต่ละหน้าเว็บที่คุณเยี่ยมชมว่าคุณมาจากหน้าเว็บใด! | Privacy Magic ลบหน้า (หรือพาธ) ที่แน่นอนใน referrer และเพื่อความเข้ากันได้ของเว็บ อนุญาตให้แชร์เฉพาะโดเมนเท่านั้น |
| Tracking Parameters | ตัวติดตามสามารถเพิ่ม "พารามิเตอร์ติดตาม" พิเศษลงในที่อยู่ของหน้าเว็บที่คุณเยี่ยมชม เพื่อให้นักโฆษณาติดตามได้ว่าคุณเป็นใครหรือเคยท่องเว็บที่ใด | Privacy Magic ลบพารามิเตอร์ติดตามที่รู้จักออกจากที่อยู่เว็บ เพื่อไม่ให้ข้อมูลนี้ถูกแชร์กับเว็บไซต์ที่คุณเยี่ยมชม |
| Window Name | โดยปกติ JavaScript API `window.name` จะรั่วข้อมูลหากคุณนำทางระหว่างเว็บไซต์ในแท็บเดียวกัน | Privacy Magic ป้องกันการรั่วไหลนี้โดยบังคับให้แต่ละเว็บไซต์มี `window.name` แยกกัน |

## การหยุดการรั่วไหลบนเว็บ {#stopping-web-leaks}

เว็บเบราว์เซอร์เป็นสิ่งที่ซับซ้อน! การรั่วไหลของข้อมูลส่วนตัวสามารถเกิดจากฟีเจอร์เบราว์เซอร์ที่แตกต่างกันมากมาย แนวทางของเราใน Privacy Magic คืออุดการรั่วไหลทุกที่ที่พบ

| ฟีเจอร์ | เว็บเบราว์เซอร์มาตรฐาน | Privacy Magic |
| :--- | :--- | :--- |
| Iframes | iframe คือ "หน้าเว็บภายในหน้าเว็บ" เป็นกล่องภายในหน้าที่คุณกำลังเยี่ยมชม ซึ่งหน้าเว็บที่สองสามารถซ่อนอยู่และใช้เทคนิคการติดตามเดียวกับที่หน้าเว็บปกติใช้ได้ | Privacy Magic ฉีดการป้องกันทั้งหมดเข้าไปในทุก iframe บนหน้าเว็บ เพื่อให้แน่ใจว่าตัวติดตามไม่สามารถเลี่ยงการป้องกันเหล่านั้นด้วยการซ่อนอยู่ใน iframe |
| Service Workers | Service Workers เป็นฟีเจอร์เบราว์เซอร์ที่ให้โค้ดรันในพื้นหลังได้แม้คุณไม่ได้เชื่อมต่ออินเทอร์เน็ต น่าเสียดายที่ Service Workers เหล่านี้รั่วข้อมูลส่วนตัวได้ง่าย | โดยทั่วไปจะปิด Service workers บนทุกไซต์ เพื่อป้องกันการรั่วไหลของข้อมูลส่วนตัวที่ไม่สามารถแพตช์ด้วยวิธีอื่นได้ |
| Shared Storage | Shared Storage เป็นฟีเจอร์เบราว์เซอร์ที่อนุญาตให้รวมและเก็บข้อมูลเกี่ยวกับการท่องเว็บของคุณ แม้จะอ้างว่าปกป้องความเป็นส่วนตัว แต่ฟีเจอร์นี้ก่อให้เกิดความกังวลด้านความเป็นส่วนตัวอย่างรุนแรง และกำลังจะถูกนำออกจากเบราว์เซอร์ | Privacy Magic ทำให้แน่ใจว่า Shared Storage ถูกปิดบนทุกเว็บไซต์ |
| Shared Workers | Shared Workers เป็นโค้ดที่รันในพื้นหลังและสามารถแชร์ระหว่างเว็บไซต์ได้ | Privacy Magic ฉีดการป้องกันเข้าไปในทุก Shared Worker ที่เว็บไซต์ใดๆ โหลด |
| Web Workers | Web Workers เป็นโค้ดที่รันในพื้นหลังบนหน้าเว็บ เช่นเดียวกับสคริปต์ของหน้าหลัก โค้ด web worker สามารถรั่วข้อมูลส่วนตัวได้ | Privacy Magic ฉีดการป้องกันเข้าไปในทุก Web Worker บนหน้า เพื่อให้แน่ใจว่าตัวติดตามไม่สามารถใช้ Web Workers เพื่อเลี่ยงการป้องกันเหล่านั้นได้ |

## สัญญาณความเป็นส่วนตัว {#privacy-signals}

เราสนใจที่จะปรับปรุงความเป็นส่วนตัวของคุณทุกทางที่เป็นไปได้ ดังนั้น Privacy Magic จึงส่งสัญญาณเพื่อเรียกร้องนโยบายที่สนับสนุนความเป็นส่วนตัวจากเว็บไซต์ที่คุณเยี่ยมชม

| สัญญาณ | เว็บเบราว์เซอร์มาตรฐาน | Privacy Magic |
| :--- | :--- | :--- |
| Global Privacy Control | Global Privacy Control เป็นสัญญาณที่ส่งไปยังเว็บไซต์ที่คุณเยี่ยมชมเพื่อแสดงว่าคุณไม่ต้องการให้ข้อมูลของคุณถูกขายหรือแชร์ น่าเสียดายที่เว็บเบราว์เซอร์ส่วนใหญ่ไม่ส่งค่าตั้งค่า Global Privacy Control โดยค่าเริ่มต้น | Privacy Magic ทำให้แน่ใจว่าเบราว์เซอร์ของคุณส่งส่วนหัว Global Privacy Control กับทุกคำขอไปยังทุกหน้าเว็บหรือทรัพยากรที่ฝังอยู่ และยังฉีดสัญญาณ JavaScript ในทุกหน้าและ iframe |

## การป้องกันของเบราว์เซอร์ {#browser-protections}

เบราว์เซอร์ประพฤติตัวไม่ดีไม่เพียงในการเรนเดอร์หน้าเว็บ แต่ยังในการส่งข้อมูลไปยังบริษัทแม่หรือบริษัทโฆษณาบุคคลที่สาม Privacy Magic ปิดพฤติกรรมที่ไม่ดีของเบราว์เซอร์หลากหลายอย่างที่มิฉะนั้นจะรั่วข้อมูลส่วนตัวของคุณ

### การปิดฟีเจอร์เว็บที่รั่วไหล {#disabling-leaky-web-features}

| ฟีเจอร์ | เว็บเบราว์เซอร์มาตรฐาน | Privacy Magic |
| :--- | :--- | :--- |
| Hyperlink Auditing | เบราว์เซอร์มาตรฐานมีฟีเจอร์ที่ให้เว็บไซต์ "ping" เซิร์ฟเวอร์ติดตามด้วยลิงก์ที่คุณคลิก | Privacy Magic ปิดการ ping นี้ |
| Third-Party Cookies | ฟีเจอร์ติดตามที่มีชื่อเสียงที่สุด Chrome อนุญาตคุกกี้บุคคลที่สามซึ่งให้ติดตามคุณจากไซต์หนึ่งไปอีกไซต์ได้ | Privacy Magic ปิดคุกกี้บุคคลที่สามโดยค่าเริ่มต้น |
| WebRTC non-proxied UDP | WebRTC เป็นความสามารถของเว็บเบราว์เซอร์ที่ให้คุณสื่อสารกับผู้ใช้เว็บคนอื่นได้โดยตรง น่าเสียดายว่าหากคุณใช้พร็อกซีเบราว์เซอร์ เบราว์เซอร์มาตรฐานที่อิง Chrome จะรั่วการสื่อสาร WebRTC ออกนอกพร็อกซี | Privacy Magic บล็อกการรั่วไหลของ WebRTC ในขณะที่ยังให้ WebRTC ทำงานบนเว็บไซต์ที่ใช้มันได้ |

### การปิดบริการคลาวด์ที่รุกล้ำ {#disabling-invasive-cloud-services}

| บริการ | เว็บเบราว์เซอร์มาตรฐาน | Privacy Magic |
| :--- | :--- | :--- |
| Alternate Error Pages | โดยค่าเริ่มต้น Chrome จะแสดงหน้าข้อผิดพลาดทางเลือกเมื่อเกิดข้อผิดพลาด เพื่อแสดงหน้าเหล่านี้ ข้อมูลเกี่ยวกับหน้าที่คุณกำลังเยี่ยมชมจะถูกส่งไปยังเซิร์ฟเวอร์ของ Google | Privacy Magic ปิดหน้าข้อผิดพลาดทางเลือกเหล่านี้เพื่อไม่ให้มีการส่งข้อมูล |
| Safe Browsing Extended Reporting | เมื่อ Safe Browsing บล็อกหน้า Chrome อาจส่งเนื้อหาของหน้าที่ถูกบล็อกไปยังเซิร์ฟเวอร์ของ Google | Privacy Magic บล็อกฟีเจอร์นี้ เพื่อไม่ให้มีการส่งข้อมูล |
| Search Suggest | โดยค่าเริ่มต้น Chrome ส่งทุกอย่างที่คุณพิมพ์ในแถบที่อยู่ไปยังเครื่องมือค้นหาเริ่มต้น (โดยทั่วไปคือ Google search) ขณะที่คุณพิมพ์ เพื่อทำข้อเสนอแนะอัตโนมัติ | Privacy Magic บล็อกการเฝ้าติดตามอย่างต่อเนื่องนี้ เพื่อให้ Chrome ส่งการค้นหาของคุณเฉพาะเมื่อคุณกด "enter" |
| Spelling Service | Chrome มี "การตรวจสะกดขั้นสูง" ที่ส่งสิ่งที่คุณพิมพ์ไปยังเซิร์ฟเวอร์ของ Google | Privacy Magic ปิดตัวเลือกนี้และอนุญาตให้ Chrome ใช้เฉพาะ "การตรวจสะกดพื้นฐาน" ในเครื่องเท่านั้น |

### การปิด API การกำหนดเป้าหมายโฆษณา {#disabling-ad-targeting-apis}

| API | เว็บเบราว์เซอร์มาตรฐาน | Privacy Magic |

### การปิดการตั้งค่า Chrome ที่รั่วไหล {#disabling-leaky-chrome-settings}

Chrome มีการตั้งค่าบางอย่างที่ขัดต่อความเป็นส่วนตัวของคุณโดยเฉพาะ: ฟังก์ชันที่เก็บข้อมูลเกี่ยวกับนิสัยการท่องเว็บของคุณและส่งไปยังเซิร์ฟเวอร์ของ Google การตั้งค่าเหล่านี้ส่วนขยายเบราว์เซอร์ควบคุมโดยตรงไม่ได้ แต่ระหว่างการตั้งค่า Privacy Magic จะช่วยคุณหาการตั้งค่าเหล่านั้นและปิดเอง

| การตั้งค่า | เว็บเบราว์เซอร์มาตรฐาน | Privacy Magic |
| :--- | :--- | :--- |
| History syncing | เมื่อคุณลงชื่อเข้าใช้ Chrome มันจะซิงค์ประวัติการท่องเว็บระหว่างอุปกรณ์ และยังบันทึกข้อมูลเดียวกันนั้นบนเซิร์ฟเวอร์ของ Google | Privacy Magic นำคุณไปยังการตั้งค่าที่ปิดการซิงค์ประวัติเพื่อเก็บประวัติการท่องเว็บของคุณไว้เป็นส่วนตัว |
| User experience metrics | Chrome ส่งเมตริกเกี่ยวกับการใช้เบราว์เซอร์ของคุณกลับไปยังเซิร์ฟเวอร์ของ Google อย่างเงียบๆ | Privacy Magic ช่วยคุณบล็อกการเก็บข้อมูลที่ซ่อนอยู่นี้ |
| Per-URL data collection | สำหรับทุก URL ที่คุณเยี่ยมชม Chrome เก็บข้อมูลที่ "ทำให้ไม่ระบุตัวตน" เกี่ยวกับการท่องเว็บบนหน้านั้นและส่งไปยัง Google | Privacy Magic ช่วยคุณปิดการตั้งค่านี้เพื่อป้องกันไม่ให้ข้อมูลถูกส่ง |
