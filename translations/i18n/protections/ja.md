Privacy Magicは、ウェブを閲覧する際のプライバシーを包括的に保護するChrome向けオープンソース拡張機能です。ブラウザは情報漏洩が多いため、Privacy Magicは[広告とトラッカーのブロック](#blocking-ads-and-trackers)、[システム情報の保護](#protecting-system-information-fingerprinting)、[追跡の痕跡の削除](#removing-tracking-breadcrumbs)、[ウェブ漏洩の阻止](#stopping-web-leaks)、[プライバシー信号の送信](#privacy-signals)、[ブラウザ保護の適用](#browser-protections)など、複数の保護レイヤーを提供します。

## 広告とトラッカーのブロック {#blocking-ads-and-trackers}

ウェブ全体で、広告、追跡スクリプト、トラッキングピクセルが、さまざまな見えない手法であなたの同意なく追いかけてきます。

Privacy Magicは人気のフィルタリストを使い、ブラウザがネットワーク上で多くの広告やトラッカーをリクエストしないようブロックします。フィルタリストは、広告がブロックされたあとに残る空き枠も非表示にします。Privacy Magicはこれらのフィルタリストの固定バージョンを使用するため、拡張機能のブロック動作は完全に再現可能で、すべてのユーザーで同一です。

| フィルタリスト | ブロック対象 |
| :--- | :--- |
| [EasyList](https://easylist.to/) | バナー、広告スクリプト、画像、動画広告を含む広告。 |
| [EasyPrivacy](https://easylist.to/) | 追跡スクリプト、ピクセル、ウェブバグ、その他の情報収集を含むトラッカー。 |
| [Fanboy's Annoyance List](https://easylist.to/) | Cookie通知、ソーシャルメディアウィジェット、ページ内ポップアップ、その他の煩わしい要素。 |
| [small oisd blocklist](https://oisd.nl/) | 追加の広告ドメイン。 |

## システム情報の保護（フィンガープリンティング） {#protecting-system-information-fingerprinting}

従来、ブラウザは尋ねてきたあらゆるウェブサイトや追跡スクリプトに、あなたのコンピュータに関する大量の情報を漏らしてしまいます！トラッカーはこのデータを集め、ウェブ閲覧中のあなたを追跡します。

| フィンガープリント | 標準のウェブブラウザ | Privacy Magic |
| :--- | :--- | :--- |
| オーディオ | ウェブブラウザの音声処理機能は、通常サウンドカードに関する情報を漏らします。 | Privacy Magicは、スクリプトが音声データを読むたびに最下位ビットを消去することで、こうした漏洩を減らします。この消去に聞こえる影響はありません。 |
| バッテリー | ウェブブラウザは通常、尋ねてきたあらゆるウェブサイトにバッテリー残量、電源に接続されているかどうか、バッテリーが空になるまでの推定時間を伝えます。 | Privacy Magicは、常に100%のバッテリーと常に接続されている電源をシミュレートすることで、この情報漏洩を止めます。 |
| ブラウザ | ウェブページはブラウザに問い合わせ、動作しているオペレーティングシステムに関する詳細情報を取得できます。 | Privacy Magicは、オペレーティングシステムごとに`navigator.platform`を単一の値に偽装します。 |
| デバイス | ウェブブラウザは、尋ねてきたあらゆるウェブサイトに、折りたたみ可能なデバイスを使っているかどうかを伝えます。 | Privacy Magicは常に、デバイスが折りたたみ可能ではないと報告します。 |
| ディスク | ウェブブラウザは通常、ウェブサイトに利用可能なディスク容量と、そのサイトがどれだけ使っているかを漏らし、コンピュータ全体の空き容量やデータの保存方式を明らかにすることがあります。 | Privacy Magicはこれらの値を全員で同じになるよう偽装します。 |
| ディスプレイ | 従来、ウェブブラウザは「動きの減少を優先」設定を含む表示設定を漏らします。 | Privacy Magicはこの漏洩を防ぎます。 |
| フォント | 標準のウェブブラウザは、システムにインストールされているカスタムフォントを漏らし、フィンガープリントを非常にユニークにしてしまう可能性があります。 | Privacy Magicは、システムにインストールされたカスタムフォントをすべてのスクリプトから隠します。ウェブページは標準のシステムフォントとダウンロードしたウェブフォントを引き続き使用できます。 |
| グラフィックス | CanvasとWebGLは、コンピュータが使用しているGPU（グラフィックスチップ）の種類を漏らす主要なフィンガープリンティング経路です。 | Privacy Magicは高度な手法でグラフィックスチップを隠しつつ、ゲームやグラフィックスを多用する他のウェブサイトを引き続き使えるようにします。 |
| キーボード | デフォルトでは、ブラウザは使用中のキーボードレイアウトを尋ねてきたあらゆるウェブサイトに漏らします。 | Privacy Magicは、ウェブサイトのスクリプトにキーボードレイアウトが明かされないようブロックします。 |
| 言語 | 通常、ウェブブラウザは承認した言語の一覧を漏らします。訪問するウェブサイトの希望言語を指定できることは重要ですが、ブラウザはユーザーの優先言語リストを明かしてしまい、情報が多すぎることがあります。 | Privacy Magicは、訪問するウェブサイトに渡せる言語を1つだけに制限します。 |
| 数学 | ウェブページ内の追跡スクリプトは、余弦や双曲線正接などのMath関数がデバイス上で示す特異な挙動を使い、他のウェブユーザーと区別できます。 | Privacy MagicはJavaScriptのMath関数をパッチし、すべてのプラットフォームで同一の挙動になるようにします。 |
| メモリ | ウェブサイトは、多くのブラウザからコンピュータ上の未使用メモリ量を調べることができます。 | Privacy Magicは、システムで利用可能なメモリ量をウェブページやトラッカーから隠します。 |
| ネットワーク | ブラウザは通常、ネットワーク接続の種類に関する詳細を漏らします。 | Privacy Magicはこれらの詳細を全ユーザーで均一にし、漏洩を防ぎます。 |
| プロセッサ | ブラウザは、コンピュータのプロセッサのコア数を報告するよう設計されています。 | Privacy Magicは、誰もがちょうど`4`個であるかのように装います。 |
| 画面 | ウェブブラウザは、ブラウザウィンドウの大きさに関係なく、尋ねてきたあらゆるウェブサイトに画面の寸法を漏らします。 | Privacy Magicは実際の画面サイズを隠します。 |
| タイムゾーン | スクリプトがタイムゾーンを尋ねると、ウェブブラウザはおおよその所在地を漏らします。たとえば中央ヨーロッパ時間にいる場合、ブラウザはパリ、ベルリン、ルクセンブルク、その他数十の都市のいずれかを示すタイムゾーン識別子を提供します。 | Privacy Magicはタイムゾーンを統合し、各タイムゾーンオフセットに対して代表となるタイムゾーンを1つだけにします。これにより、地球上の位置について不要な情報が漏れることはありません。 |
| タイミング | 高解像度のタイミングAPIにより、スクリプトはブラウザ挙動のわずかな時間差を測定してシステムを特徴づけられます。 | Privacy MagicはこれらのAPIが返す時刻を丸め、追跡スクリプトがブラウザを区別するのに使うのをはるかに難しくします。 |
| タッチ | Touch APIは、デバイスにタッチがあるか、何タッチポイントまで許可するかを漏らします。 | Privacy Magicはこの情報をウェブサイトから隠します。 |

## 追跡の痕跡の削除 {#removing-tracking-breadcrumbs}

一部のブラウザ機能は、閲覧履歴の一部（「パンくず」）を訪問するさまざまなウェブサイトに共有するために悪用されやすいです。Privacy Magicはこれらの機能を強化し、漏洩しにくくします。

| 痕跡 | 標準のウェブブラウザ | Privacy Magic |
| :--- | :--- | :--- |
| キャッシュ漏洩 | ブラウザはデータをローカルキャッシュに保存するため、ページを再訪問したり再度表示したりする際に、そのデータを二度読み込む必要がありません。残念ながら、これらのキャッシュは時に漏洩し、訪問したウェブサイトに閲覧履歴の一端を明かしてしまいます。 | Privacy Magicは脆弱なキャッシュをクリアし、こうした漏洩が起きないようにします。 |
| リファラーポリシー | 従来、ブラウザは訪問する各ウェブページに、どのページから来たかを伝えてしまいます！ | Privacy Magicはリファラー内の正確なページ（またはパス）を削除し、ウェブ互換性のためドメインのみの共有を許可します。 |
| トラッキングパラメータ | トラッカーは訪問するウェブページのアドレスに余分な「トラッキングパラメータ」を追加し、広告主があなたが誰か、どこを閲覧したかを追跡できるようにします。 | Privacy Magicはウェブアドレスから既知のトラッキングパラメータを削除し、この情報が訪問先のウェブサイトと共有されないようにします。 |
| Window Name | 通常、`window.name` JavaScript APIは、同じタブ内でウェブサイト間を移動するとデータを漏らします。 | Privacy Magicはウェブサイトごとに別々の`window.name`を強制することで、この漏洩を防ぎます。 |

## ウェブ漏洩の阻止 {#stopping-web-leaks}

ウェブブラウザは複雑な存在です！個人情報の漏洩は、さまざまなブラウザ機能から生じ得ます。Privacy Magicのアプローチは、見つかった漏洩をどこでも塞ぐことです。

| 機能 | 標準のウェブブラウザ | Privacy Magic |
| :--- | :--- | :--- |
| Iframes | iframeは「ウェブページ内のウェブページ」です。訪問中のページ内の枠で、別のウェブページが隠れ、通常のウェブページと同じ追跡手法をすべて使えます。 | Privacy Magicはウェブページ上のすべてのiframeに保護機能を注入し、トラッカーがiframe内に隠れて保護を迂回できないようにします。 |
| Service Workers | Service Workersは、インターネットに接続していなくてもバックグラウンドでコードを実行できるブラウザ機能です。残念ながら、これらのService Workersは個人情報を簡単に漏らしてしまいます。 | 他の方法では修正できない個人情報の漏洩を防ぐため、Service workersは原則としてすべてのサイトで無効化されます。 |
| Shared Storage | Shared Storageは、閲覧に関するデータを集約・収集できるブラウザ機能です。プライバシーを保護すると謳われていましたが、強いプライバシー上の懸念を招き、ブラウザから削除される予定です。 | Privacy Magicは、すべてのウェブサイトでShared Storageが無効であることを確実にします。 |
| Shared Workers | Shared Workersはバックグラウンドで動作し、ウェブサイト間で共有できるコードです。 | Privacy Magicは、あらゆるウェブサイトが読み込むすべてのShared Workerに保護機能を注入します。 |
| Web Workers | Web Workersはウェブページ上でバックグラウンド実行されるコードです。メインページのスクリプトと同様に、Web Workerのコードも個人データを漏らす可能性があります。 | Privacy Magicはページ上のすべてのWeb Workerに保護機能を注入し、トラッカーがWeb Workersを使って保護を迂回できないようにします。 |

## プライバシー信号 {#privacy-signals}

私たちはあらゆる方法であなたのプライバシーを改善したいと考えています。そのためPrivacy Magicは、訪問するウェブサイトにプライバシー重視のポリシーを求める信号を送信します。

| 信号 | 標準のウェブブラウザ | Privacy Magic |
| :--- | :--- | :--- |
| Global Privacy Control | Global Privacy Controlは、訪問するウェブサイトにデータの販売や共有を望まないことを示す信号です。残念ながら、ほとんどのウェブブラウザはデフォルトでGlobal Privacy Controlの設定を送信しません。 | Privacy Magicは、すべてのウェブページや埋め込みリソースへのすべてのリクエストで、ブラウザがGlobal Privacy Controlヘッダーを送信することを保証します。また、すべてのページとiframeにJavaScript信号も注入します。 |

## ブラウザ保護 {#browser-protections}

ブラウザの問題ある挙動は、ウェブページの表示方法だけでなく、親会社や第三者の広告会社へのデータ送信にも現れます。Privacy Magicは、そうでなければ個人情報を漏らしてしまうさまざまな悪いブラウザ挙動を無効化します。

### 漏洩しやすいウェブ機能の無効化 {#disabling-leaky-web-features}

| 機能 | 標準のウェブブラウザ | Privacy Magic |
| :--- | :--- | :--- |
| ハイパーリンク監査 | 標準ブラウザには、クリックしたリンクで追跡サーバーに「ping」を送れる機能があります。 | Privacy Magicはこのpingを無効化します。 |
| サードパーティCookie | 最も有名な追跡機能です。Chromeはサイト間での追跡を可能にするサードパーティCookieを許可しています。 | Privacy MagicはデフォルトでサードパーティCookieを無効化します。 |
| WebRTCの非プロキシUDP | WebRTCは、他のウェブユーザーと直接通信できるウェブブラウザの機能です。残念ながら、ブラウザプロキシを使っている場合、標準のChrome系ブラウザはプロキシの外にWebRTC通信を漏らしてしまいます。 | Privacy MagicはWebRTCの漏洩をブロックしつつ、WebRTCを使うウェブサイトでは引き続き機能できるようにします。 |

### 侵襲的なクラウドサービスの無効化 {#disabling-invasive-cloud-services}

| サービス | 標準のウェブブラウザ | Privacy Magic |
| :--- | :--- | :--- |
| 代替エラーページ | デフォルトでは、Chromeはエラー発生時に代替エラーページを表示します。これらのページを表示するため、訪問中のページに関するデータがGoogleのサーバーに送信されます。 | Privacy Magicはこれらの代替エラーページを無効化し、データが送信されないようにします。 |
| Safe Browsing拡張レポート | Safe Browsingがページをブロックすると、Chromeはブロックされたページの内容をGoogleのサーバーに送信することがあります。 | Privacy Magicはこの機能をブロックし、データが送信されないようにします。 |
| 検索候補 | デフォルトでは、Chromeはアドレスバーに入力した内容を入力中にデフォルトの検索エンジン（通常はGoogle検索）へ送信し、自動候補を表示します。 | Privacy Magicはこの継続的な監視をブロックし、「Enter」を押したときだけ検索が送信されるようにします。 |
| スペルチェックサービス | Chromeは、入力内容をGoogleのサーバーに送信する「強化スペルチェック」を提供しています。 | Privacy Magicはこのオプションを無効化し、Chromeがローカルの「基本スペルチェック」のみを使えるようにします。 |

### 広告ターゲティングAPIの無効化 {#disabling-ad-targeting-apis}

| API | 標準のウェブブラウザ | Privacy Magic |
| :--- | :--- | :--- |
| Ad Measurement API | Ad Measurement API（および関連するPrivate Aggregation API）は、閲覧、クリックした広告、その他の個人データを広告サーバーに送信します。 | Privacy Magicはデータを保護するため、これらのAPIを無効化します。 |
| Protected Audience API | デフォルトでは、このAPIは広告主のためにあなたの注目をオークションにかけるため、Chromeから利用可能になっています。 | Privacy MagicはこのAPIを無効化し、閲覧データがそのように使われないようにします。 |
| Topics API | ChromeのTopics APIは、あなたが関心を持つとされるトピックの一覧を広告主に渡します。 | Privacy MagicはTopics APIを無効化し、そのデータを非公開に保ちます。 |

### 漏洩しやすいChrome設定の無効化 {#disabling-leaky-chrome-settings}

Chromeにはプライバシーに反する特定の設定があります。具体的には、閲覧習慣に関するデータを収集してGoogleのサーバーに送信する機能です。これらの設定はブラウザ拡張機能から直接制御できませんが、セットアップ時にPrivacy Magicが設定を見つけて自分でオフにする手助けをします。

| 設定 | 標準のウェブブラウザ | Privacy Magic |
| :--- | :--- | :--- |
| 履歴の同期 | Chromeにサインインしていると、閲覧履歴をデバイス間で同期します。同じデータはGoogleのサーバーにも保存されます。 | Privacy Magicは、閲覧履歴を非公開に保つため、履歴同期を無効にする設定へ案内します。 |
| ユーザー体験メトリクス | Chromeはブラウザの使用状況に関するメトリクスを、静かにGoogleのサーバーへ送り返します。 | Privacy Magicは、この隠れたデータ収集をブロックする手助けをします。 |
| URLごとのデータ収集 | 訪問するすべてのURLについて、Chromeはそれらのページでの閲覧に関する「匿名化された」データを収集し、Googleに送信します。 | Privacy Magicは、この設定を無効化してデータ送信を防ぐ手助けをします。 |
