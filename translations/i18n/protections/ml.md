Privacy Magic എന്നത് വെബ് ബ്രൗസ് ചെയ്യുമ്പോൾ നിങ്ങളുടെ സ്വകാര്യത സമഗ്രമായി സംരക്ഷിക്കുന്ന Chrome-നുള്ള ഒരു ഓപ്പൺ സോഴ്‌സ് എക്സ്റ്റൻഷനാണ്. ബ്രൗസറുകൾ വളരെ ചോർച്ചയുള്ളവയാണ്, അതിനാൽ Privacy Magic [പരസ്യങ്ങളും ട്രാക്കറുകളും തടയൽ](#blocking-ads-and-trackers), [സിസ്റ്റം വിവരങ്ങൾ സംരക്ഷിക്കൽ](#protecting-system-information-fingerprinting), [ട്രാക്കിംഗ് ബ്രെഡ്‌ക്രംബുകൾ നീക്കം ചെയ്യൽ](#removing-tracking-breadcrumbs), [വെബ് ചോർച്ചകൾ നിർത്തൽ](#stopping-web-leaks), [സ്വകാര്യത സിഗ്നലുകൾ അയയ്ക്കൽ](#privacy-signals), [ബ്രൗസർ സംരക്ഷണങ്ങൾ നടപ്പിലാക്കൽ](#browser-protections) എന്നിവ ഉൾപ്പെടെ ഒന്നിലധികം സംരക്ഷണ പാളികൾ നൽകുന്നു.

## പരസ്യങ്ങളും ട്രാക്കറുകളും തടയൽ {#blocking-ads-and-trackers}

വെബിലുടനീളം, പരസ്യങ്ങൾ, ട്രാക്കിംഗ് സ്‌ക്രിപ്റ്റുകൾ, ട്രാക്കിംഗ് പിക്സലുകൾ എന്നിവ വിവിധ അദൃശ്യ രീതികൾ ഉപയോഗിച്ച് നിങ്ങളുടെ സമ്മതമില്ലാതെ നിങ്ങളെ പിന്തുടരുന്നു.

Privacy Magic ജനപ്രിയ ഫിൽട്ടർ ലിസ്റ്റുകൾ ഉപയോഗിച്ച് നിങ്ങളുടെ ബ്രൗസർ നെറ്റ്‌വർക്കിൽ അഭ്യർത്ഥിക്കുന്ന പല പരസ്യങ്ങളും ട്രാക്കറുകളും തടയുന്നു. പരസ്യങ്ങൾ തടഞ്ഞതിന് ശേഷം വെബ് പേജിൽ അവശേഷിക്കുന്ന ശൂന്യമായ ബോക്സുകളും ഫിൽട്ടർ ലിസ്റ്റുകൾ മറയ്ക്കുന്നു. എക്സ്റ്റൻഷന്റെ തടയൽ പെരുമാറ്റം പൂർണ്ണമായും പുനരുൽപ്പാദിപ്പിക്കാവുന്നതും ഓരോ ഉപയോക്താവിനും സമാനവുമാക്കാൻ Privacy Magic ഈ ഫിൽട്ടർ ലിസ്റ്റുകളുടെ പിൻ ചെയ്ത പതിപ്പ് ഉപയോഗിക്കുന്നു.

## സിസ്റ്റം വിവരങ്ങൾ സംരക്ഷിക്കൽ (ഫിംഗർപ്രിന്റിംഗ്) {#protecting-system-information-fingerprinting}

| Service Workers | നിങ്ങൾ ഇന്റർനെറ്റുമായി ബന്ധിപ്പിച്ചിട്ടില്ലാത്തപ്പോഴും പശ്ചാത്തലത്തിൽ കോഡ് പ്രവർത്തിക്കാൻ അനുവദിക്കുന്ന ഒരു ബ്രൗസർ ഫീച്ചറാണ് Service Workers. നിർഭാഗ്യവശാൽ, ഈ Service Workers-ന് സ്വകാര്യ വിവരങ്ങൾ എളുപ്പത്തിൽ ചോർത്താൻ കഴിയും. | മറ്റുവിധത്തിൽ പാച്ച് ചെയ്യാൻ കഴിയാത്ത സ്വകാര്യ വിവര ചോർച്ചകൾ തടയാൻ, എല്ലാ സൈറ്റുകളിലും service workers പൊതുവെ പ്രവർത്തനരഹിതമാക്കിയിരിക്കുന്നു. |
| Shared Storage | നിങ്ങളുടെ ബ്രൗസിംഗിനെക്കുറിച്ചുള്ള ഡാറ്റ അഗ്രിഗേറ്റ് ചെയ്ത് ശേഖരിക്കാൻ അനുവദിക്കുന്ന ഒരു ബ്രൗസർ ഫീച്ചറാണ് Shared Storage. ഇത് സ്വകാര്യത സംരക്ഷിക്കുന്നതായി അവകാശപ്പെട്ടിരുന്നെങ്കിലും, ഈ ഫീച്ചർ ശക്തമായ സ്വകാര്യത ആശങ്കകൾ ഉയർത്തി, ബ്രൗസറുകളിൽ നിന്ന് നീക്കം ചെയ്യാനിരിക്കുകയാണ്. | എല്ലാ വെബ്‌സൈറ്റുകളിലും Shared Storage പ്രവർത്തനരഹിതമാണെന്ന് Privacy Magic ഉറപ്പാക്കുന്നു. |
| Shared Workers | പശ്ചാത്തലത്തിൽ പ്രവർത്തിക്കുകയും വെബ്‌സൈറ്റുകൾക്കിടയിൽ പങ്കിടാൻ കഴിയുകയും ചെയ്യുന്ന കോഡാണ് Shared Workers. | ഏതൊരു വെബ്‌സൈറ്റും ലോഡ് ചെയ്യുന്ന ഓരോ Shared Worker-ലും Privacy Magic അതിന്റെ സംരക്ഷണങ്ങൾ കുത്തിവയ്ക്കുന്നു. |
| Web Workers | ഒരു വെബ് പേജിൽ പശ്ചാത്തലത്തിൽ പ്രവർത്തിക്കുന്ന കോഡാണ് Web Workers. പ്രധാന പേജിന്റെ സ്‌ക്രിപ്റ്റുകളെപ്പോലെ, web worker കോഡിന് സ്വകാര്യ ഡാറ്റ ചോർത്താൻ കഴിയും. | ട്രാക്കറുകൾക്ക് ആ സംരക്ഷണങ്ങൾ മറികടക്കാൻ Web Workers ഉപയോഗിക്കാൻ കഴിയാതിരിക്കാൻ, ഒരു പേജിലെ ഓരോ Web Worker-ലും Privacy Magic അതിന്റെ സംരക്ഷണങ്ങൾ കുത്തിവയ്ക്കുന്നു. |

## സ്വകാര്യത സിഗ്നലുകൾ {#privacy-signals}

സാധ്യമായ എല്ലാ വിധത്തിലും നിങ്ങളുടെ സ്വകാര്യത മെച്ചപ്പെടുത്തുന്നതിൽ ഞങ്ങൾക്ക് താൽപ്പര്യമുണ്ട്. അതിനാൽ നിങ്ങൾ സന്ദർശിക്കുന്ന വെബ്‌സൈറ്റുകളിൽ നിന്ന് സ്വകാര്യതാ-സൗഹൃദ നയങ്ങൾ ആവശ്യപ്പെടാൻ Privacy Magic ഒരു സിഗ്നൽ അയയ്ക്കുന്നു.

| സിഗ്നൽ | സ്റ്റാൻഡേർഡ് വെബ് ബ്രൗസറുകൾ | Privacy Magic |
| :--- | :--- | :--- |
| Global Privacy Control | നിങ്ങളുടെ ഡാറ്റ വിൽക്കുകയോ പങ്കിടുകയോ ചെയ്യരുതെന്ന് സൂചിപ്പിക്കാൻ നിങ്ങൾ സന്ദർശിക്കുന്ന വെബ്‌സൈറ്റുകളിലേക്ക് അയയ്ക്കാവുന്ന ഒരു സിഗ്നലാണ് Global Privacy Control. നിർഭാഗ്യവശാൽ, മിക്ക വെബ് ബ്രൗസറുകളും ഡിഫോൾട്ടായി Global Privacy Control മുൻഗണന അയയ്ക്കുന്നില്ല. | ഓരോ വെബ് പേജിലേക്കോ എംബഡഡ് റിസോഴ്‌സിലേക്കോ ഉള്ള ഓരോ അഭ്യർത്ഥനയോടും നിങ്ങളുടെ ബ്രൗസർ Global Privacy Control ഹെഡർ അയയ്ക്കുന്നുവെന്ന് Privacy Magic ഉറപ്പാക്കുന്നു. ഓരോ പേജിലും iframe-ലും ഒരു JavaScript സിഗ്നലും അത് കുത്തിവയ്ക്കുന്നു. |

## ബ്രൗസർ സംരക്ഷണങ്ങൾ {#browser-protections}

വെബ് പേജുകൾ റെൻഡർ ചെയ്യുന്ന വിധത്തിൽ മാത്രമല്ല, പാരന്റ് കമ്പനിയിലേക്കോ മൂന്നാം കക്ഷി പരസ്യ കമ്പനികളിലേക്കോ ഡാറ്റ അയയ്ക്കുന്ന വിധത്തിലും ബ്രൗസറുകൾ മോശമായി പെരുമാറുന്നു. അല്ലാത്തപക്ഷം നിങ്ങളുടെ സ്വകാര്യ വിവരങ്ങൾ ചോർത്തുന്ന വിവിധ മോശം ബ്രൗസർ പെരുമാറ്റങ്ങൾ Privacy Magic പ്രവർത്തനരഹിതമാക്കുന്നു.

### ചോർച്ചയുള്ള വെബ് ഫീച്ചറുകൾ പ്രവർത്തനരഹിതമാക്കൽ {#disabling-leaky-web-features}

| ഫീച്ചർ | സ്റ്റാൻഡേർഡ് വെബ് ബ്രൗസറുകൾ | Privacy Magic |

| WebRTC non-proxied UDP | മറ്റ് വെബ് ഉപയോക്താക്കളുമായി നേരിട്ട് ആശയവിനിമയം നടത്താൻ അനുവദിക്കുന്ന ഒരു വെബ് ബ്രൗസർ കഴിവാണ് WebRTC. നിർഭാഗ്യവശാൽ, നിങ്ങൾ ഒരു ബ്രൗസർ പ്രോക്സി ഉപയോഗിക്കുന്നുണ്ടെങ്കിൽ, സ്റ്റാൻഡേർഡ് Chrome അധിഷ്ഠിത ബ്രൗസറുകൾ പ്രോക്സിക്ക് പുറത്ത് WebRTC ആശയവിനിമയങ്ങൾ ചോർത്തും. | അത് ഉപയോഗിക്കുന്ന വെബ്‌സൈറ്റുകളിൽ WebRTC പ്രവർത്തിക്കാൻ അനുവദിച്ചുകൊണ്ട് തന്നെ Privacy Magic WebRTC ചോർച്ചകൾ തടയുന്നു. |

| Topics API | നിങ്ങൾക്ക് താൽപ്പര്യമുണ്ടെന്ന് കരുതപ്പെടുന്ന വിഷയങ്ങളുടെ ഒരു ലിസ്റ്റ് Chrome-ന്റെ Topics API പരസ്യദാതാക്കൾക്ക് നൽകുന്നു. | ആ ഡാറ്റ സ്വകാര്യമായി സൂക്ഷിക്കാൻ Privacy Magic Topics API പ്രവർത്തനരഹിതമാക്കുന്നു. |

### ചോർച്ചയുള്ള Chrome ക്രമീകരണങ്ങൾ പ്രവർത്തനരഹിതമാക്കൽ {#disabling-leaky-chrome-settings}

Chrome-ൽ നിങ്ങളുടെ സ്വകാര്യതയ്ക്ക് വിരുദ്ധമായ ചില ക്രമീകരണങ്ങളുണ്ട്: പ്രത്യേകിച്ച്, നിങ്ങളുടെ ബ്രൗസിംഗ് ശീലങ്ങളെക്കുറിച്ചുള്ള ഡാറ്റ ശേഖരിച്ച് Google-ന്റെ സെർവറുകളിലേക്ക് അയയ്ക്കുന്ന ഫംഗ്ഷണാലിറ്റി. ഈ ക്രമീകരണങ്ങൾ ഒരു ബ്രൗസർ എക്സ്റ്റൻഷന് നേരിട്ട് നിയന്ത്രിക്കാൻ കഴിയില്ല, എന്നാൽ സജ്ജീകരണ സമയത്ത്, ക്രമീകരണങ്ങൾ കണ്ടെത്തി സ്വയം ഓഫ് ചെയ്യാൻ Privacy Magic നിങ്ങളെ സഹായിക്കും.
