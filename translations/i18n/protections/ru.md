Privacy Magic — это расширение с открытым исходным кодом для Chrome, которое всесторонне защищает вашу конфиденциальность при просмотре веб-страниц. Браузеры сильно «протекают», поэтому Privacy Magic обеспечивает несколько уровней защиты, включая [блокировку рекламы и трекеров](#blocking-ads-and-trackers), [защиту системной информации](#protecting-system-information-fingerprinting), [удаление следов отслеживания](#removing-tracking-breadcrumbs), [остановку веб-утечек](#stopping-web-leaks), [отправку сигналов конфиденциальности](#privacy-signals) и [применение защит браузера](#browser-protections).

## Блокировка рекламы и трекеров {#blocking-ads-and-trackers}

По всему интернету реклама, скрипты отслеживания и пиксели слежения следуют за вами без вашего согласия, используя множество невидимых методов.

Privacy Magic использует популярные списки фильтров, чтобы блокировать запросы многих рекламных объявлений и трекеров вашим браузером по сети. Списки фильтров также скрывают пустые блоки, которые остаются после блокировки рекламы на странице. Privacy Magic использует зафиксированную версию этих списков фильтров, чтобы поведение блокировки расширения было полностью воспроизводимым и одинаковым для каждого пользователя.

| Список фильтров | Что блокируется |
| :--- | :--- |
| [EasyList](https://easylist.to/) | Реклама, включая баннеры, рекламные скрипты, изображения и видеорекламу. |
| [EasyPrivacy](https://easylist.to/) | Трекеры, включая скрипты отслеживания, пиксели, веб-жучки и другие сборщики информации. |
| [Fanboy's Annoyance List](https://easylist.to/) | Уведомления о cookie, виджеты социальных сетей, всплывающие окна на странице и другие раздражители. |
| [small oisd blocklist](https://oisd.nl/) | Дополнительные рекламные домены. |

## Защита системной информации (fingerprinting) {#protecting-system-information-fingerprinting}

Традиционно браузеры передают огромные объёмы информации о вашем компьютере любому сайту или скрипту отслеживания, который её запросит! А трекеры собирают эти данные, чтобы следить за вами во время просмотра веб-страниц.

| Отпечаток | Обычные веб-браузеры | Privacy Magic |
| :--- | :--- | :--- |
| Аудио | Функции обработки звука в браузерах обычно раскрывают информацию о вашей звуковой карте. | Privacy Magic снижает такие утечки, стирая младший бит из аудиоданных при каждом чтении скриптом. Это стирание не влияет на слышимый звук. |
| Батарея | Браузеры обычно сообщают любому запрашивающему сайту уровень заряда батареи, подключён ли устройство к сети и оценку оставшегося времени до разрядки. | Privacy Magic останавливает эту утечку, имитируя батарею всегда на 100% и постоянно подключённый источник питания. |
| Браузер | Веб-страница может опрашивать ваш браузер, чтобы получить подробную информацию об операционной системе, в которой он работает. | Privacy Magic подменяет `navigator.platform` одним значением для каждой операционной системы. |
| Устройство | Браузеры сообщают любому запрашивающему сайту, используете ли вы складное устройство. | Privacy Magic всегда сообщает, что ваше устройство не складное. |
| Диск | Браузеры обычно раскрывают объём дискового пространства, доступный сайту, и сколько сайт использует — это может выявить общий объём диска вашего компьютера и способ хранения данных. | Privacy Magic подменяет эти значения так, чтобы они были одинаковыми для всех. |
| Дисплей | Традиционно браузеры раскрывают настройки дисплея, в том числе включён ли режим «предпочитать уменьшенное движение». | Privacy Magic предотвращает эту утечку. |
| Шрифты | Обычные браузеры раскрывают, какие пользовательские шрифты установлены в вашей системе, что может сделать ваш отпечаток очень уникальным. | Privacy Magic скрывает пользовательские шрифты вашей системы от всех скриптов. Веб-страницы по-прежнему могут использовать стандартные системные шрифты и загружаемые веб-шрифты. |
| Графика | Canvas и WebGL — два основных вектора fingerprinting, раскрывающих тип GPU (графического чипа) вашего компьютера. | Privacy Magic использует продвинутые методы, чтобы скрыть графический чип, позволяя при этом играть в игры и пользоваться сайтами с интенсивной графикой. |
| Клавиатура | По умолчанию браузеры раскрывают раскладку клавиатуры любому запрашивающему сайту. | Privacy Magic блокирует раскрытие раскладки клавиатуры скриптам сайтов. |
| Язык | Обычно браузеры раскрывают список языков, которые вы одобрили. Хотя важно иметь возможность указать предпочтительный язык для посещаемых сайтов, браузеры обычно выдают список предпочтительных языков пользователя, что может быть слишком информативным. | Privacy Magic позволяет передавать посещаемым сайтам только один язык. |
| Математика | Скрипты отслеживания на веб-страницах могут использовать характерное поведение математических функций, таких как косинус или гиперболический тангенс, на вашем устройстве, чтобы отличить вас от других пользователей. | Privacy Magic исправляет функции Math в JavaScript так, чтобы они вели себя одинаково на всех платформах. |
| Память | Сайты могут узнать у большинства браузеров, сколько неиспользуемой памяти есть на вашем компьютере. | Privacy Magic скрывает объём доступной памяти вашей системы от веб-страниц и трекеров. |
| Сеть | Браузеры обычно раскрывают сведения о типе вашего сетевого подключения. | Privacy Magic предотвращает утечку этих сведений, делая их одинаковыми для всех пользователей. |
| Процессор | Браузеры предназначены сообщать число ядер процессора вашего компьютера. | Privacy Magic делает вид, что у всех ровно `4`. |
| Экран | Браузеры раскрывают размеры вашего экрана любому запрашивающему сайту, независимо от размера окна браузера. | Privacy Magic скрывает настоящий размер экрана. |
| Часовой пояс | Браузеры раскрывают ваше приблизительное местоположение, когда скрипты запрашивают часовой пояс. Например, если вы в центральноевропейском времени, браузер предоставит идентификатор часового пояса, указывающий, находитесь ли вы в Париже, Берлине, Люксембурге или в одном из десятков других городов. | Privacy Magic объединяет часовые пояса так, чтобы у каждого смещения был один представительский пояс. Таким образом браузер не раскрывает лишнюю информацию о вашем местоположении на планете. |
| Тайминг | API высокоточного измерения времени позволяют скриптам характеризовать вашу систему, измеряя крошечные различия во времени поведения браузера. | Privacy Magic округляет времена, предоставляемые этими API, чтобы трекерам было гораздо сложнее использовать их для различения браузеров. |
| Касание | Touch API раскрывает, есть ли у вашего устройства сенсорный ввод и сколько точек касания он допускает. | Privacy Magic скрывает эту информацию от сайтов. |

## Удаление следов отслеживания {#removing-tracking-breadcrumbs}

Некоторые функции браузера уязвимы к использованию для передачи частей вашей истории просмотра («хлебных крошек») разным посещаемым сайтам. Privacy Magic усиливает эти функции, чтобы они меньше «протекали».

| След | Обычные веб-браузеры | Privacy Magic |
| :--- | :--- | :--- |
| Утечки кэша | Браузеры хранят данные в локальных кэшах, чтобы при повторном посещении страницы эти данные не нужно было загружать снова. К сожалению, эти кэши иногда «протекают» и раскрывают что-то о вашей истории просмотра посещаемому сайту. | Privacy Magic очищает уязвимые кэши, чтобы такие утечки не происходили. |
| Политика Referrer | Традиционно браузеры сообщают каждой посещаемой веб-странице, с какой страницы вы пришли! | Privacy Magic удаляет точную страницу (или путь) из referrer и ради веб-совместимости разрешает передавать только домен. |
| Параметры отслеживания | Трекеры могут добавлять дополнительные «параметры отслеживания» к адресам посещаемых страниц, чтобы рекламодатели могли отслеживать, кто вы и где вы бывали. | Privacy Magic удаляет известные параметры отслеживания из веб-адресов, чтобы эта информация не передавалась посещаемым сайтам. |
| Имя окна | Обычно JavaScript API `window.name` раскрывает данные при переходе между сайтами в одной вкладке. | Privacy Magic предотвращает эту утечку, принуждая отдельный `window.name` для каждого сайта. |

## Остановка веб-утечек {#stopping-web-leaks}

Веб-браузеры — сложные существа! Утечки частной информации могут возникать из самых разных функций браузера. Подход Privacy Magic — устранять утечки везде, где они обнаружены.

| Функция | Обычные веб-браузеры | Privacy Magic |
| :--- | :--- | :--- |
| Iframes | Iframe — это «веб-страница внутри веб-страницы». Это блок внутри посещаемой страницы, где вторая страница может скрываться и использовать те же техники отслеживания, что и обычная страница. | Privacy Magic внедряет все свои защиты в каждый iframe на странице, чтобы трекер не мог обойти их, спрятавшись внутри iframe. |
| Service Workers | Service Workers — функция браузера, позволяющая коду работать в фоне даже без подключения к интернету. К сожалению, эти Service Workers легко могут раскрывать частную информацию. | Service Workers в целом отключены на всех сайтах, чтобы предотвратить утечки частной информации, которые иначе нельзя исправить. |
| Shared Storage | Shared Storage — функция браузера, позволяющая агрегировать и собирать данные о вашем просмотре. Хотя её позиционировали как сохраняющую конфиденциальность, эта функция вызвала серьёзные опасения и должна быть удалена из браузеров. | Privacy Magic гарантирует, что Shared Storage отключён на всех сайтах. |
| Shared Workers | Shared Workers — код, работающий в фоне и доступный для совместного использования между сайтами. | Privacy Magic внедряет свои защиты в каждый Shared Worker, загружаемый любым сайтом. |
| Web Workers | Web Workers — код, работающий в фоне на веб-странице. Как и скрипты основной страницы, код web worker может раскрывать частные данные. | Privacy Magic внедряет свои защиты в каждый Web Worker на странице, чтобы трекеры не могли использовать Web Workers для обхода этих защит. |

## Сигналы конфиденциальности {#privacy-signals}

Мы стремимся улучшать вашу конфиденциальность всеми возможными способами. Поэтому Privacy Magic отправляет сигнал с требованием политик, поддерживающих конфиденциальность, от посещаемых сайтов.

| Сигнал | Обычные веб-браузеры | Privacy Magic |
| :--- | :--- | :--- |
| Global Privacy Control | Global Privacy Control — сигнал, который можно отправлять посещаемым сайтам, чтобы указать, что вы не хотите продажи или передачи ваших данных. К сожалению, большинство браузеров по умолчанию не отправляют предпочтение Global Privacy Control. | Privacy Magic гарантирует, что ваш браузер отправляет заголовок Global Privacy Control с каждым запросом к каждой веб-странице или встроенному ресурсу. Также внедряется JavaScript-сигнал на каждую страницу и в каждый iframe. |

## Защиты браузера {#browser-protections}

Браузеры плохо себя ведут не только в том, как они отображают веб-страницы, но и в том, как отправляют данные материнской компании или сторонним рекламным компаниям. Privacy Magic отключает ряд вредных поведения браузера, которые иначе раскрывали бы вашу частную информацию.

### Отключение «протекающих» веб-функций {#disabling-leaky-web-features}

| Функция | Обычные веб-браузеры | Privacy Magic |
| :--- | :--- | :--- |
| Аудит гиперссылок | В обычных браузерах есть функция, позволяющая сайтам «пинговать» сервер отслеживания при кликах по ссылкам. | Privacy Magic отключает этот ping. |
| Сторонние cookie | Самая известная функция отслеживания. Chrome разрешает сторонние cookie, позволяющие отслеживать вас от сайта к сайту. | Privacy Magic по умолчанию отключает сторонние cookie. |
| WebRTC UDP без прокси | WebRTC — возможность браузера напрямую общаться с другими пользователями сети. К сожалению, если вы используете прокси браузера, обычные браузеры на базе Chrome раскрывают WebRTC-связь в обход прокси. | Privacy Magic блокирует утечки WebRTC, сохраняя при этом работу WebRTC на сайтах, которые его используют. |

### Отключение навязчивых облачных сервисов {#disabling-invasive-cloud-services}

| Сервис | Обычные веб-браузеры | Privacy Magic |
| :--- | :--- | :--- |
| Альтернативные страницы ошибок | По умолчанию Chrome показывает альтернативные страницы ошибок при возникновении ошибки. Для их отображения данные о посещаемых страницах отправляются на серверы Google. | Privacy Magic отключает эти альтернативные страницы ошибок, чтобы данные не отправлялись. |
| Safe Browsing Extended Reporting | Когда Safe Browsing блокирует страницу, Chrome может отправлять содержимое заблокированной страницы на серверы Google. | Privacy Magic блокирует эту функцию, чтобы данные не отправлялись. |
| Подсказки поиска | По умолчанию Chrome отправляет всё, что вы вводите в адресную строку, в поисковую систему по умолчанию (обычно Google), пока вы печатаете, чтобы показывать автоподсказки. | Privacy Magic блокирует этот непрерывный мониторинг, чтобы Chrome отправлял ваш запрос только при нажатии «Enter». |
| Служба проверки орфографии | Chrome предлагает «улучшенную проверку орфографии», которая отправляет набираемый текст на серверы Google. | Privacy Magic отключает этот параметр и разрешает Chrome использовать только локальную «базовую проверку орфографии». |

### Отключение API таргетинга рекламы {#disabling-ad-targeting-apis}

| API | Обычные веб-браузеры | Privacy Magic |
| :--- | :--- | :--- |
| Ad Measurement API | Ad Measurement API (и связанный Private Aggregation API) отправляет данные о вашем просмотре, рекламе, по которой вы кликаете, и другие частные данные на рекламные серверы. | Privacy Magic отключает эти API для защиты ваших данных. |
| Protected Audience API | По умолчанию этот API доступен в Chrome для проведения аукциона за ваше внимание от имени рекламодателей. | Privacy Magic отключает этот API, чтобы ваши данные просмотра не использовались таким образом. |
| Topics API | Topics API в Chrome даёт рекламодателям список тем, которые якобы вас интересуют. | Privacy Magic отключает Topics API, чтобы сохранить эти данные в тайне. |

### Отключение «протекающих» настроек Chrome {#disabling-leaky-chrome-settings}

В Chrome есть определённые настройки, противоречащие вашей конфиденциальности: а именно функции, которые собирают данные о ваших привычках просмотра и отправляют их на серверы Google. Эти настройки нельзя напрямую контролировать расширением браузера, но при настройке Privacy Magic поможет вам найти их и отключить самостоятельно.

| Настройка | Обычные веб-браузеры | Privacy Magic |
| :--- | :--- | :--- |
| Синхронизация истории | Когда вы вошли в Chrome, он синхронизирует историю просмотра между устройствами. Он также сохраняет те же данные на серверах Google. | Privacy Magic направляет вас к настройке, отключающей синхронизацию истории, чтобы сохранить историю просмотра в тайне. |
| Метрики пользовательского опыта | Chrome незаметно отправляет метрики об использовании браузера на серверы Google. | Privacy Magic помогает вам заблокировать этот скрытый сбор данных. |
| Сбор данных по URL | Для каждого посещаемого URL Chrome собирает «анонимизированные» данные о вашем просмотре этих страниц и отправляет их в Google. | Privacy Magic помогает вам отключить эту настройку, чтобы предотвратить отправку данных. |
