Πώς μπορούμε εμείς, οι απλοί άνθρωποι, να προστατευτούμε από τη μαζική παρακολούθηση; Εργάζομαι πάνω σε αυτό το πρόβλημα με τον έναν ή τον άλλον τρόπο για πάνω από μια δεκαετία. Σε αυτό το διάστημα, έχω εργαστεί σε τρεις περιηγητές ιστού προσανατολισμένους στο απόρρητο: Tor Browser, Firefox και Brave. Εκατομμύρια άνθρωποι χρησιμοποιούν αυτούς τους περιηγητές κάθε μέρα και προστατεύονται, τουλάχιστον σε κάποιο βαθμό, από την ηλεκτρονική κατασκοπεία.

Όμως παρά κάποια πρόοδο στη βελτίωση του απορρήτου τους, αυτοί οι εξειδικευμένοι περιηγητές δεν είναι πιθανό να κατακτήσουν μεγάλο μερίδιο της αγοράς περιηγητών. Η πραγματικότητα είναι ότι οι περισσότεροι άνθρωποι εξακολουθούν να επιλέγουν mainstream περιηγητές, αφήνοντάς τους σε μεγάλο βαθμό απροστάτευτους από την παρακολούθηση.

Η επιλογή ενός mainstream περιηγητή είναι κατανοητή! Το Chrome και το Edge είναι προεγκατεστημένα στους περισσότερους υπολογιστές και προσφέρουν ισχυρή απόδοση. Σε επιτραπέζιους υπολογιστές, σχεδόν το 90% των χρηστών χρησιμοποιεί mainstream περιηγητές βασισμένους στο Chromium. Το μειονέκτημα είναι ότι οι περιηγητές διαρρέουν άφθονες ιδιωτικές πληροφορίες.

Οι διαρρέοντες περιηγητές (και άλλο διαρρέον λογισμικό) διευκολύνουν εταιρείες και κυβερνήσεις να κατασκοπεύουν όλους. Οργανισμοί συλλέγουν λεπτομερείς πληροφορίες για κάθε άτομο χρησιμοποιώντας δεδομένα που αποκτούν από τη χρήση του διαδικτύου σας. Κατά την άποψή μου, αυτή η μαζική παρακολούθηση αποτελεί απειλή για τη δημοκρατία και απειλή για την ανθρώπινη ζωή.

Τι μπορούμε λοιπόν να κάνουμε για όσους θέλουν να προστατεύσουν το απόρρητό τους αλλά θέλουν επίσης να μείνουν στον περιηγητή Chrome; Χρειαζόμαστε μια λύση που να εγκαθίσταται εύκολα, να χρησιμοποιείται εύκολα και να προστατεύει το απόρρητό σας, χωρίς όμως να υποβαθμίζει την εμπειρία περιήγησης ή να περιορίζει την ελευθερία σας να χρησιμοποιείτε τον ιστό όπως θέλετε. Με άλλα λόγια, πρέπει να λειτουργεί σαν «μαγεία».

Συνειδητοποίησα ότι μια προσεκτικά σχεδιασμένη επέκταση περιηγητή μπορεί να ταιριάζει. Το Chrome Web Store προσφέρει ήδη χιλιάδες επεκτάσεις που κάνουν τεράστια ποικιλία πραγμάτων, συμπεριλαμβανομένου του μπλοκαρίσματος διαφημίσεων ή της αποτροπής ορισμένων διαρροών ιδιωτικών πληροφοριών. Αλλά καμία επέκταση δεν προσφέρει μια *ολοκληρωμένη* σουίτα προστασιών απορρήτου που να αντιμετωπίζει τους πολυάριθμους τρόπους με τους οποίους το απόρρητό σας μπορεί να υπονομευθεί στο διαδίκτυο.

Για να υλοποιήσω αυτή την ιδέα, δημιούργησα το Privacy Magic, μια επέκταση απορρήτου περιηγητή τύπου «ρύθμισε και ξέχνα». Η κατασκευή του Privacy Magic δεν ήταν μικρή προσπάθεια: οι mainstream περιηγητές ιστού, ειλικρινά, διαρρέουν σαν κόσκινο. Για να μην βυθιστεί ένα κόσκινο, πρέπει να βουλώσεις όλες τις τρύπες. Το Privacy Magic προσπαθεί να το κάνει αυτό περιλαμβάνοντας μεγάλη ποικιλία προστασιών, οι περισσότερες από τις οποίες κατασκευάστηκαν από το μηδέν για αυτή την επέκταση, και όλες είναι ενεργοποιημένες από προεπιλογή.

Αυτές οι προστασίες περιλαμβάνουν αυτόματο μπλοκάρισμα διαφημίσεων και ιχνηλατών (παρόμοιο με adblocker, αλλά ομοιόμορφο για όλους τους χρήστες), αντίσταση στο δακτυλικό αποτύπωμα (μπλοκάρισμα κάθε είδους διαρροών πληροφοριών για τη συσκευή σας), μπλοκάρισμα ιχνών (ώστε οι ιστοσελίδες να μην μπορούν να «επισημάνουν» τον περιηγητή σας), σφράγιση διαρροών περιηγητή (σκλήρυνση πραγμάτων όπως iframes και web workers), μπλοκάρισμα cookies τρίτων, απενεργοποίηση λειτουργιών αντι-απορρήτου στον περιηγητή (όπως το λεγόμενο Ad Measurement) και ενεργοποίηση του Global Privacy Control (ένα μήνυμα που απαιτεί από τις ιστοσελίδες να μην πουλούν τα δεδομένα σας).

Όλες αυτές οι προστασίες απορρήτου έχουν σχεδιαστεί ώστε να αποφεύγουν την παρεμβολή στην περιήγησή σας. Αν όμως τυχόν συναντήσετε μια ιστοσελίδα που δεν λειτουργεί με το Privacy Magic εκτός κουτιού, μπορείτε να απενεργοποιήσετε τις προστασίες μόνο σε αυτή την ιστοσελίδα κάνοντας κλικ στο κουμπί <span class="post-inline-logo" aria-hidden="true"><img src="/images/logo.svg" alt=""></span> και απενεργοποιώντας το.

Εκτός από τις προστασίες εντός περιηγητή που προσφέρει το Privacy Magic, είναι απαραίτητο να κρατήσετε τη διεύθυνση IP σας ασφαλή από αδιάκριτα μάτια. Κατά την εγκατάσταση, η επέκταση σας παρέχει σύνδεσμο προς τα συνιστώμενα VPN του Privacy Guides που θα κρύψουν τη διεύθυνση IP σας από ιστοσελίδες και ενσωματωμένους ιχνηλάτες.

Χαίρομαι που μπορώ να πω ότι οι προστασίες απορρήτου του Privacy Magic είναι διεξοδικές και, όσο γνωρίζω, υπερβαίνουν σημαντικά τις προστασίες που προσφέρει οποιαδήποτε άλλη επέκταση Chrome. Είμαι αποφασισμένος να συνεχίσω να ενισχύω και να επεκτείνω τη σουίτα προστασιών απορρήτου για να παρέχω μια λύση που «απλώς δουλεύει». Και σχεδιάζω να υποστηρίξω και άλλους περιηγητές στο μέλλον, τόσο σε επιτραπέζιους όσο και σε κινητές συσκευές.

Η μαζική παρακολούθηση δεν θα σταματήσει από εξειδικευμένα εργαλεία: πρέπει να δώσουμε σε *όλους* τους ανθρώπους τα εργαλεία που χρειάζονται για να προστατευτούν. Το αντίδοτο στη μαζική παρακολούθηση είναι η μαζική προστασία. Ελπίζω το Privacy Magic να αποτελέσει σημαντική συμβολή σε αυτή την προσπάθεια.
