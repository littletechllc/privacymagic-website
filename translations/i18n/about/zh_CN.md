作为普通人，我们如何保护自己免受大规模监控？十余年来，我一直以这样或那样的方式致力于解决这个问题。在那段时间里，我参与过三款注重隐私的网页浏览器：Tor Browser、Firefox 和 Brave。每天有数百万人使用这些浏览器，并至少在一定程度上免受在线窥探。

但尽管在改善隐私方面取得了一些进展，这些小众浏览器不太可能占据浏览器市场的很大份额。现实是，大多数人仍选择使用主流浏览器，从而在很大程度上暴露于监控之下。

选择主流浏览器是可以理解的！Chrome 和 Edge 预装在大多数电脑上，并提供出色的性能。在桌面端，接近 90% 的用户使用基于 Chromium 的主流浏览器。缺点是这些浏览器会泄露大量私人信息。

会泄露的浏览器（以及其他会泄露的软件）让企业和政府很容易监视所有人。各组织正利用从您的互联网使用中获取的数据，收集关于每个人的详细信息。在我看来，这种大规模监控是对民主的威胁，也是对人类生命的威胁。

那么，对于那些既想保护隐私又想继续使用 Chrome 浏览器的人，我们能做什么？我们需要一个易于安装、易于使用、能保护您隐私，但又不会降低浏览体验或限制您按自己意愿使用网络的解决方案。换句话说，它需要像“魔法”一样工作。

我意识到，一款精心设计的浏览器扩展或许正好合适。Chrome Web Store 已经提供了数千款扩展，功能五花八门，包括拦截广告或防止某些私人信息泄露。但没有一款扩展能提供*全面*的隐私保护套件，以应对您的在线隐私可能被侵害的众多方式。

为实现这一想法，我创建了 Privacy Magic——一款“设置后即可放心使用”的浏览器隐私扩展。打造 Privacy Magic 绝非易事：说实话，主流网页浏览器像筛子一样到处漏。要想让筛子不沉，就必须堵住所有漏洞。Privacy Magic 试图通过包含大量保护措施来做到这一点，其中大多数是为本扩展从零构建的，并且全部默认启用。

这些保护措施包括：自动拦截广告和跟踪器（类似于广告拦截器，但对所有用户保持一致）、抵御指纹识别（拦截关于您设备的各种信息泄露）、拦截痕迹（防止网站“标记”您的浏览器）、封堵网页浏览器漏洞（强化 iframe 和 web workers 等）、拦截第三方 Cookie、禁用浏览器中的反隐私功能（例如所谓的 Ad Measurement），以及启用 Global Privacy Control（一条要求网站不要出售您数据的消息）。

所有这些隐私保护都经过设计，以避免干扰您的浏览。但如果碰巧遇到某网站无法在 Privacy Magic 下正常工作，您可以点击 <span class="post-inline-logo" aria-hidden="true"><img src="/images/logo.svg" alt=""></span> 按钮并关闭，仅在该网站上禁用保护。

除了 Privacy Magic 提供的浏览器内保护外，保护您的 IP 地址不被窥探也很关键。安装过程中，扩展会为您提供指向 Privacy Guides 推荐 VPN 的链接，这些 VPN 可对网站和嵌入式跟踪器隐藏您的 IP 地址。

我很高兴地说，Privacy Magic 的隐私保护非常全面，据我所知，远超其他任何 Chrome 扩展所提供的保护。我决心继续收紧并扩展隐私保护套件，以提供一个“开箱即用”的解决方案。我也计划在未来支持其他浏览器，包括桌面端和移动端。

大规模监控不会被小众工具阻止：我们需要为*所有*人提供自我保护所需的工具。应对大规模监控的解药是大规模保护。我希望 Privacy Magic 能成为这一努力的重要贡献。
