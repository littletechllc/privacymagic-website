作為普通人，我們如何保護自己免受大規模監控？十多年來，我一直以這樣或那樣的方式致力於解決這個問題。在那段時間裡，我參與過三款注重隱私的網頁瀏覽器：Tor Browser、Firefox 和 Brave。每天有數百萬人使用這些瀏覽器，並至少在一定程度上免受線上窺探。

但儘管在改善隱私方面取得了一些進展，這些小眾瀏覽器不太可能佔有瀏覽器市場的很大份額。現實是，大多數人仍選擇使用主流瀏覽器，從而在很大程度上暴露於監控之下。

選擇主流瀏覽器是可以理解的！Chrome 和 Edge 預裝在大多數電腦上，並提供出色的效能。在桌面端，接近 90% 的使用者使用基於 Chromium 的主流瀏覽器。缺點是這些瀏覽器會洩漏大量私人資訊。

會洩漏的瀏覽器（以及其他會洩漏的軟體）讓企業和政府很容易監視所有人。各組織正利用從您的網際網路使用中取得的資料，收集關於每個人的詳細資訊。在我看來，這種大規模監控是對民主的威脅，也是對人類生命的威脅。

那麼，對於那些既想保護隱私又想繼續使用 Chrome 瀏覽器的人，我們能做什麼？我們需要一個易於安裝、易於使用、能保護您隱私，但又不會降低瀏覽體驗或限制您按自己意願使用網路的解決方案。換句話說，它需要像「魔法」一樣運作。

我意識到，一款精心設計的瀏覽器擴充功能或許正好合適。Chrome Web Store 已經提供了數千款擴充功能，功能五花八門，包括攔截廣告或防止某些私人資訊洩漏。但沒有一款擴充功能能提供*全面*的隱私保護套件，以應對您的線上隱私可能被侵害的眾多方式。

為實現這一想法，我建立了 Privacy Magic——一款「設定後即可放心使用」的瀏覽器隱私擴充功能。打造 Privacy Magic 絕非易事：說實話，主流網頁瀏覽器像篩子一樣到處漏。要想讓篩子不沉，就必須堵住所有漏洞。Privacy Magic 試圖透過包含大量保護措施來做到這一點，其中大多數是為本擴充功能從零建構的，並且全部預設啟用。

這些保護措施包括：自動攔截廣告和追蹤器（類似於廣告攔截器，但對所有使用者保持一致）、抵禦指紋辨識（攔截關於您裝置的各種資訊洩漏）、攔截痕跡（防止網站「標記」您的瀏覽器）、封堵網頁瀏覽器漏洞（強化 iframe 和 web workers 等）、攔截第三方 Cookie、停用瀏覽器中的反隱私功能（例如所謂的 Ad Measurement），以及啟用 Global Privacy Control（一則要求網站不要出售您資料的訊息）。

所有這些隱私保護都經過設計，以避免干擾您的瀏覽。但如果碰巧遇到某網站無法在 Privacy Magic 下正常運作，您可以點擊 <span class="post-inline-logo" aria-hidden="true"><img src="/images/logo.svg" alt=""></span> 按鈕並關閉，僅在該網站上停用保護。

除了 Privacy Magic 提供的瀏覽器內保護外，保護您的 IP 位址不被窺探也很關鍵。安裝過程中，擴充功能會為您提供指向 Privacy Guides 推薦 VPN 的連結，這些 VPN 可對網站和內嵌追蹤器隱藏您的 IP 位址。

我很高興地說，Privacy Magic 的隱私保護非常全面，據我所知，遠超其他任何 Chrome 擴充功能所提供的保護。我決心繼續收緊並擴展隱私保護套件，以提供一個「開箱即用」的解決方案。我也計劃在未來支援其他瀏覽器，包括桌面端和行動端。

大規模監控不會被小眾工具阻止：我們需要為*所有*人提供自我保護所需的工具。應對大規模監控的解藥是大規模保護。我希望 Privacy Magic 能成為這一努力的重要貢獻。
