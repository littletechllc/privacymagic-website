સુરક્ષા: તમારા બ્રાઉઝરમાં લીક બંધ કરવી

Privacy Magic વેબ બ્રાઉઝ કરતી વખતે તમારી ગોપનીયતાનું રક્ષણ કેવી રીતે કરે છે

Privacy Magic એ Chrome માટેનું ઓપન-સોર્સ એક્સટેન્શન છે જે વેબ બ્રાઉઝ કરતી વખતે તમારી ગોપનીયતાનું વ્યાપક રક્ષણ કરે છે. બ્રાઉઝર ખૂબ લીકી હોય છે, તેથી Privacy Magic બહુવિધ સ્તરની સુરક્ષા પૂરી પાડે છે, જેમાં જાહેરાતો અને ટ્રેકર્સ બ્લોક કરવા, સિસ્ટમ માહિતીનું રક્ષણ, ટ્રેકિંગ બ્રેડક્રમ્બ્સ દૂર કરવા, વેબ લીક રોકવા, ગોપનીયતા સિગ્નલ મોકલવા, અને બ્રાઉઝર સુરક્ષા લાગુ કરવી સામેલ છે.

જાહેરાતો અને ટ્રેકર્સ બ્લોક કરવા

સમગ્ર વેબ પર, જાહેરાતો, ટ્રેકિંગ સ્ક્રિપ્ટ્સ અને ટ્રેકિંગ પિક્સલ્સ તમારી સંમતિ વગર વિવિધ અદૃશ્ય પદ્ધતિઓથી તમને અનુસરે છે.

Privacy Magic લોકપ્રિય ફિલ્ટર યાદીઓ વાપરીને ઘણી જાહેરાતો અને ટ્રેકર્સને નેટવર્ક પર તમારા બ્રાઉઝર દ્વારા વિનંતી થવાથી બ્લોક કરે છે. ફિલ્ટર યાદીઓ તે ખાલી બૉક્સ પણ છુપાવે છે જે વેબ પેજ પર જાહેરાતો બ્લોક થાય ત્યારે રહી જાય છે. Privacy Magic આ ફિલ્ટર યાદીઓનું પિન કરેલું વર્ઝન વાપરે છે જેથી એક્સટેન્શનનું બ્લોકિંગ વર્તન સંપૂર્ણપણે પુનઃઉત્પાદનયોગ્ય અને દરેક વપરાશકર્તા માટે સમાન રહે.

પરંપરાગત રીતે, બ્રાઉઝર તમારા કમ્પ્યુટર વિશે ભરપૂર માહિતી કોઈપણ વેબસાઇટ અથવા ટ્રેકિંગ સ્ક્રિપ્ટને લીક કરે છે જે માંગે! અને ટ્રેકર્સ આ ડેટા એકત્ર કરીને વેબ બ્રાઉઝ કરતી વખતે તમને અનુસરે છે.

ફિંગરપ્રિન્ટ માનક વેબ બ્રાઉઝર Privacy Magic
ઓડિયો બ્રાઉઝરની ઓડિયો પ્રોસેસિંગ કાર્યક્ષમતા સામાન્ય રીતે તમારા સાઉન્ડ કાર્ડ વિશે માહિતી લીક કરે છે. Privacy Magic સ્ક્રિપ્ટ દ્વારા ઓડિયો ડેટા વાંચાય ત્યારે સૌથી ઓછા મહત્વનું બિટ મિટાવીને આવી લીક ઘટાડે છે. આ મિટાવવાની કોઈ શ્રવ્ય અસર નથી.
બેટરી બ્રાઉઝર સામાન્ય રીતે કોઈપણ માંગતી વેબસાઇટને કહે છે કે તમારી બેટરી લેવલ કેટલી છે, તમારું ડિવાઇસ પાવર સોર્સમાં પ્લગ થયેલું છે કે નહીં, અને બેટરી ખાલી થાય તે પહેલાં કેટલો સમય બાકી છે. Privacy Magic હંમેશા 100% બેટરી અને હંમેશા પ્લગ્ડ-ઇન પાવર સપ્લાયનું અનુકરણ કરીને આ માહિતી લીક રોકે છે.
બ્રાઉઝર વેબ પેજ તમારા બ્રાઉઝરને પૂછપરછ કરીને તે જે ઓપરેટિંગ સિસ્ટમમાં ચાલી રહ્યું છે તેની વિગતવાર માહિતી મેળવી શકે છે. Privacy Magic દરેક અલગ ઓપરેટિંગ સિસ્ટમ માટે navigator.platformને એક જ મૂલ્ય પર સ્પૂફ કરે છે.
ડિવાઇસ વેબ બ્રાઉઝર કોઈપણ માંગતી વેબસાઇટને કહે છે કે તમે ફોલ્ડેબલ ડિવાઇસ વાપરી રહ્યા છો કે નહીં. Privacy Magic હંમેશા રિપોર્ટ કરે છે કે તમારું ડિવાઇસ ફોલ્ડેબલ નથી.
ડિસ્ક વેબ બ્રાઉઝર સામાન્ય રીતે વેબસાઇટ માટે ઉપલબ્ધ ડિસ્ક સ્પેસ અને તે વેબસાઇટ કેટલી વાપરી રહી છે તે લીક કરે છે, જે તમારા કમ્પ્યુટર પર કુલ ડિસ્ક સ્પેસ અને ડેટા કેવી રીતે સંગ્રહાય છે તે જાહેર કરી શકે છે. Privacy Magic આ મૂલ્યોને સ્પૂફ કરે છે જેથી તે બધા માટે સમાન રહે.
ડિસ્પ્લે પરંપરાગત રીતે વેબ બ્રાઉઝર ડિસ્પ્લે સેટિંગ્સ લીક કરે છે, જેમાં તમારી સિસ્ટમ "prefer reduced motion" પર સેટ છે કે નહીં તે પણ સામેલ છે. Privacy Magic આ લીક અટકાવે છે.
ફોન્ટ માનક વેબ બ્રાઉઝર લીક કરે છે કે તમારી સિસ્ટમ પર કયા કસ્ટમ ફોન્ટ ઇન્સ્ટોલ છે, જેનાથી તમારી ફિંગરપ્રિન્ટ ખૂબ અનોખી બની શકે છે. Privacy Magic સિસ્ટમ પર ઇન્સ્ટોલ કસ્ટમ ફોન્ટ બધી સ્ક્રિપ્ટથી છુપાવે છે. વેબ પેજ માનક સિસ્ટમ ફોન્ટ અને ડાઉનલોડ કરેલા વેબ ફોન્ટ વાપરવાનું ચાલુ રાખી શકે છે.
ગ્રાફિક્સ Canvas અને WebGL બે મુખ્ય ફિંગરપ્રિન્ટિંગ વેક્ટર છે જે લીક કરે છે કે તમારું કમ્પ્યુટર કયા પ્રકારનું GPU (ગ્રાફિક્સ ચિપ) વાપરી રહ્યું છે. Privacy Magic અદ્યતન તકનીકોથી ગ્રાફિક્સ ચિપ છુપાવે છે, છતાં તમે ગેમ રમી શકો અને ગ્રાફિક્સનો ભારે ઉપયોગ કરતી અન્ય વેબસાઇટ્સ વાપરી શકો.
કીબોર્ડ ડિફોલ્ટ રીતે, બ્રાઉઝર તમે વાપરતા કીબોર્ડ લેઆઉટને કોઈપણ માંગતી વેબસાઇટ પર લીક કરે છે. Privacy Magic તમારા કીબોર્ડ લેઆઉટને વેબસાઇટ સ્ક્રિપ્ટને જાહેર થવાથી બ્લોક કરે છે.
ભાષા સામાન્ય રીતે, વેબ બ્રાઉઝર તમે મંજૂર કરેલી ભાષાઓની યાદી લીક કરે છે. તમે મુલાકાત લો છો તે વેબસાઇટ્સ માટે પસંદની ભાષા જણાવવી મહત્વપૂર્ણ છે, પરંતુ બ્રાઉઝર સામાન્ય રીતે વપરાશકર્તાની પસંદની ભાષાઓની યાદી જાહેર કરે છે, જે વધુ પડતી માહિતી આપી શકે છે. Privacy Magic તમે મુલાકાત લો છો તે વેબસાઇટ્સને ફક્ત એક ભાષા મોકલવાની મંજૂરી આપે છે.
Math વેબ પેજમાં ટ્રેકિંગ સ્ક્રિપ્ટ્સ તમારા ડિવાઇસ પર Math ફંક્શન્સ—જેમ કે cosine અથવા hyperbolic tangent—ના વિચિત્ર વર્તનનો ઉપયોગ કરીને તમને અન્ય વેબ વપરાશકર્તાઓથી અલગ કરી શકે છે. Privacy Magic JavaScript Math ફંક્શન્સને પેચ કરે છે જેથી તે બધા પ્લેટફોર્મ પર સમાન રીતે વર્તે.
મેમરી વેબસાઇટ્સ મોટાભાગના બ્રાઉઝરથી જાણી શકે છે કે તમારા કમ્પ્યુટર પર કેટલી મેમરી વણવપરાયેલી છે. Privacy Magic તમારી સિસ્ટમ પર ઉપલબ્ધ મેમરીની માત્રાને વેબ પેજ અને ટ્રેકર્સથી છુપાવે છે.
નેટવર્ક બ્રાઉઝર સામાન્ય રીતે તમારા નેટવર્ક કનેક્શનના પ્રકાર વિશે વિગતો લીક કરે છે. Privacy Magic આ વિગતોને બધા વપરાશકર્તાઓ માટે એકસમાન બનાવીને લીક થવાથી અટકાવે છે.
પ્રોસેસર બ્રાઉઝર તમારા કમ્પ્યુટરના પ્રોસેસર પર કોરની સંખ્યા રિપોર્ટ કરવા માટે ડિઝાઇન થયેલા છે. Privacy Magic દેખાવ કરે છે કે દરેકની પાસે બરાબર 4 છે.
સ્ક્રીન બ્રાઉઝર વિન્ડો ગમે તેટલી મોટી હોય, વેબ બ્રાઉઝર તમારી સ્ક્રીનના પરિમાણો કોઈપણ માંગતી વેબસાઇટ પર લીક કરે છે. Privacy Magic ખરું સ્ક્રીન કદ છુપાવે છે.
સમય ક્ષેત્ર સ્ક્રિપ્ટ્સ તમારું સમય ક્ષેત્ર માંગે ત્યારે વેબ બ્રાઉઝર તમારું અંદાજિત સ્થાન લીક કરે છે. ઉદાહરણ તરીકે, જો તમે Central European Timeમાં છો, તો બ્રાઉઝર એવું સમય ક્ષેત્ર ઓળખકર્તા આપશે જે સૂચવશે કે તમે પેરિસ, બર્લિન, લક્ઝમબર્ગ અથવા ડઝનો અન્ય શહેરોમાંથી કોઈમાં છો. Privacy Magic સમય ક્ષેત્રોને એકત્રિત કરે છે જેથી દરેક સમય ક્ષેત્ર ઓફસેટનું એક જ પ્રતિનિધિ સમય ક્ષેત્ર હોય. આમ બ્રાઉઝર ગ્લોબ પર તમારા સ્થાન વિશે બિનજરૂરી માહિતી લીક કરતું નથી.
ટાઇમિંગ ઉચ્ચ રિઝોલ્યુશન ટાઇમિંગ API સ્ક્રિપ્ટ્સને બ્રાઉઝર વર્તનની ટાઇમિંગમાં સૂક્ષ્મ તફાવત માપીને તમારી સિસ્ટમનું લક્ષણ નિર્ધારિત કરવા દે છે. Privacy Magic આ API દ્વારા આપેલા સમયને રાઉન્ડ કરે છે જેથી ટ્રેકિંગ સ્ક્રિપ્ટ્સ માટે તેનો ઉપયોગ કરીને બ્રાઉઝર અલગ પાડવું ઘણું મુશ્કેલ બને.
ટચ Touch API લીક કરે છે કે તમારા ડિવાઇસમાં ટચ છે કે નહીં અને તે કેટલા ટચ પોઇન્ટને મંજૂરી આપે છે. Privacy Magic આ માહિતીને વેબસાઇટ્સથી છુપાવે છે.

ટ્રેકિંગ બ્રેડક્રમ્બ્સ દૂર કરવા

કેટલીક બ્રાઉઝર સુવિધાઓ તમારા બ્રાઉઝિંગ ઇતિહાસના ભાગો ("બ્રેડક્રમ્બ્સ") તમે મુલાકાત લો છો તે વિવિધ વેબસાઇટ્સ સાથે શેર કરવા માટે નબળી છે. Privacy Magic આ સુવિધાઓને મજબૂત બનાવે છે જેથી તે ઓછી લીકી હોય.

બ્રેડક્રમ્બ માનક વેબ બ્રાઉઝર Privacy Magic
Cache Leaks બ્રાઉઝર સ્થાનિક કૅશમાં ડેટા સંગ્રહે છે, જેથી તમે પેજ બીજી વાર જુઓ ત્યારે તે ડેટા ફરીથી લોડ કરવાની જરૂર ન પડે. કમનસીબે, તે કૅશ ક્યારેક લીકી હોય છે અને તમે મુલાકાત લો છો તે વેબસાઇટને તમારા બ્રાઉઝિંગ ઇતિહાસ વિશે કંઈક જાહેર કરે છે. Privacy Magic નબળા કૅશ સાફ કરે છે જેથી આ લીક ન થઈ શકે.
Re­fer­rer Pol­i­cy પરંપરાગત રીતે, બ્રાઉઝર તમે મુલાકાત લો છો તે દરેક વેબ પેજને કહે છે કે તમે કયા વેબ પેજથી આવ્યા છો! Privacy Magic રેફરરમાં ચોક્કસ પેજ (અથવા પાથ) કાઢી નાખે છે, અને વેબ સુસંગતતા માટે ફક્ત ડોમેન શેર કરવાની મંજૂરી આપે છે.
Track­ing Pa­ra­me­ters ટ્રેકર્સ તમે મુલાકાત લો છો તે વેબ પેજના સરનામામાં વધારાના "ટ્રેકિંગ પેરામીટર્સ" ઉમેરી શકે છે, જેથી જાહેરાતકર્તાઓ તમે કોણ છો અથવા ક્યાં બ્રાઉઝ કર્યું છે તે ટ્રેક કરી શકે. Privacy Magic વેબ સરનામાંમાંથી જાણીતા ટ્રેકિંગ પેરામીટર્સ કાઢી નાખે છે જેથી આ માહિતી તમે મુલાકાત લો છો તે વેબસાઇટ્સ સાથે શેર ન થાય.
Win­dow Name સામાન્ય રીતે, window.name JavaScript API જો તમે એક જ ટૅબમાં વેબસાઇટ્સ વચ્ચે નેવિગેટ કરો તો ડેટા લીક કરે છે. Privacy Magic દરેક વેબસાઇટ માટે અલગ window.name લાગુ કરીને આ લીક અટકાવે છે.

વેબ લીક રોકવા

વેબ બ્રાઉઝર જટિલ પ્રાણી છે! ખાનગી માહિતીની લીક ઘણી અલગ બ્રાઉઝર સુવિધાઓમાંથી નીકળી શકે છે. Privacy Magicમાં અમારો અભિગમ છે કે જ્યાં પણ લીક મળે ત્યાં તેને બંધ કરવી.

સુવિધા માનક વેબ બ્રાઉઝર Privacy Magic
Iframes iframe એ "વેબ પેજની અંદર વેબ પેજ" છે. તમે મુલાકાત લો છો તે પેજની અંદરનું બૉક્સ, જ્યાં બીજું વેબ પેજ છુપાઈને સામાન્ય વેબ પેજ જેવી બધી ટ્રેકિંગ તકનીકો વાપરી શકે છે. Privacy Magic વેબ પેજ પરના દરેક iframeમાં તેની બધી સુરક્ષા ઇન્જેક્ટ કરે છે, જેથી ટ્રેકર iframeમાં છુપાઈને તે સુરક્ષા બાયપાસ ન કરી શકે.
Ser­vice Work­ers Service Workers એ બ્રાઉઝર સુવિધા છે જે તમે ઇન્ટરનેટ સાથે જોડાયેલા ન હો ત્યારે પણ બેકગ્રાઉન્ડમાં કોડ ચલાવવા દે છે. કમનસીબે, આ Service Workers સરળતાથી ખાનગી માહિતી લીક કરી શકે છે. ખાનગી માહિતીની લીક રોકવા માટે Service workers સામાન્ય રીતે બધી સાઇટ્સ પર અક્ષમ હોય છે, જે અન્યથા પેચ કરી શકાતી નથી.
Shared Stor­age Shared Storage એ બ્રાઉઝર સુવિધા છે જે તમારા બ્રાઉઝિંગ વિશેનો ડેટા એકત્રિત અને એકત્ર કરવા દે છે. જોકે તેને ગોપનીયતા-સંરક્ષક તરીકે દાવો કરાયો હતો, આ સુવિધાએ મજબૂત ગોપનીયતા ચિંતાઓ ઉભી કરી અને તે બ્રાઉઝરમાંથી દૂર થવાની છે. Privacy Magic ખાતરી કરે છે કે Shared Storage બધી વેબસાઇટ્સ પર અક્ષમ છે.
Shared Work­ers Shared Workers એ બેકગ્રાઉન્ડમાં ચાલતો કોડ છે જે વેબસાઇટ્સ વચ્ચે શેર થઈ શકે છે. Privacy Magic કોઈપણ વેબસાઇટ દ્વારા લોડ થયેલા દરેક Shared Workerમાં તેની સુરક્ષા ઇન્જેક્ટ કરે છે.
Web Work­ers Web Workers એ વેબ પેજ પર બેકગ્રાઉન્ડમાં ચાલતો કોડ છે. મુખ્ય પેજની સ્ક્રિપ્ટ્સની જેમ, web worker કોડ ખાનગી ડેટા લીક કરી શકે છે. Privacy Magic પેજ પરના દરેક Web Workerમાં તેની સુરક્ષા ઇન્જેક્ટ કરે છે, જેથી ટ્રેકર્સ Web Workers વાપરીને તે સુરક્ષા બાયપાસ ન કરી શકે.

ગોપનીયતા સિગ્નલ

અમે દરેક શક્ય રીતે તમારી ગોપનીયતા સુધારવામાં રસ ધરાવીએ છીએ. તેથી Privacy Magic તમે મુલાકાત લો છો તે વેબસાઇટ્સ પાસેથી ગોપનીયતા-મૈત્રીપૂર્ણ નીતિઓની માંગ કરતું સિગ્નલ મોકલે છે.

સિગ્નલ માનક વેબ બ્રાઉઝર Privacy Magic
Glob­al Pri­va­cy Con­trol Global Privacy Control એ સિગ્નલ છે જે તમે મુલાકાત લો છો તે વેબસાઇટ્સને મોકલી શકાય છે કે તમે તમારો ડેટા વેચવો કે શેર કરવો નથી માંગતા. કમનસીબે, મોટાભાગના વેબ બ્રાઉઝર ડિફોલ્ટ રીતે Global Privacy Control પસંદગી મોકલતા નથી. Privacy Magic ખાતરી કરે છે કે તમારું બ્રાઉઝર દરેક વેબ પેજ અથવા એમ્બેડેડ રિસોર્સ પર દરેક વિનંતી સાથે Global Privacy Control હેડર મોકલે. તે દરેક પેજ અને iframeમાં JavaScript સિગ્નલ પણ ઇન્જેક્ટ કરે છે.

બ્રાઉઝર સુરક્ષા

બ્રાઉઝર ફક્ત વેબ પેજ રેન્ડર કરવામાં જ નહીં, પરંતુ પેરેંટ કંપની અથવા તૃતીય-પક્ષ જાહેરાત કંપનીઓને ડેટા મોકલવામાં પણ ખરાબ વર્તન કરે છે. Privacy Magic વિવિધ ખરાબ બ્રાઉઝર વર્તન અક્ષમ કરે છે જે અન્યથા તમારી ખાનગી માહિતી લીક કરત.

લીકી વેબ સુવિધાઓ અક્ષમ કરવી

સુવિધા માનક વેબ બ્રાઉઝર Privacy Magic
Hy­per­link Au­dit­ing માનક બ્રાઉઝરમાં એવી સુવિધા છે જે વેબસાઇટ્સને તમે ક્લિક કરો છો તે લિંક્સ સાથે ટ્રેકિંગ સર્વરને "પિંગ" કરવા દે છે. Privacy Magic આ પિંગ અક્ષમ કરે છે.
Third-Par­ty Cook­ies બધામાં સૌથી પ્રખ્યાત ટ્રેકિંગ સુવિધા. Chrome તૃતીય-પક્ષ કુકીઝને મંજૂરી આપે છે જે તમને સાઇટથી સાઇટ સુધી ટ્રેક કરવા દે છે. Privacy Magic ડિફોલ્ટ રીતે તૃતીય-પક્ષ કુકીઝ અક્ષમ કરે છે.
Web­RTC non-prox­ied UDP WebRTC એ વેબ બ્રાઉઝર ક્ષમતા છે જે તમને અન્ય વેબ વપરાશકર્તાઓ સાથે સીધો સંવાદ કરવા દે છે. કમનસીબે, જો તમે બ્રાઉઝર પ્રોક્સી વાપરતા હો, તો માનક Chrome-આધારિત બ્રાઉઝર પ્રોક્સીની બહાર WebRTC સંવાદ લીક કરે છે. Privacy Magic WebRTC લીક બ્લોક કરે છે, છતાં જે વેબસાઇટ્સ તે વાપરે છે ત્યાં WebRTC કાર્ય કરવા દે છે.

આક્રમક ક્લાઉડ સેવાઓ અક્ષમ કરવી

સેવા માનક વેબ બ્રાઉઝર Privacy Magic
Al­ter­nate Er­ror Pages ડિફોલ્ટ રીતે, ભૂલ થાય ત્યારે Chrome વૈકલ્પિક એરર પેજ બતાવે છે. આ પેજ બતાવવા માટે, તમે કયા પેજ મુલાકાત લો છો તે વિશેનો ડેટા Googleના સર્વર પર મોકલાય છે. Privacy Magic આ વૈકલ્પિક એરર પેજ અક્ષમ કરે છે જેથી કોઈ ડેટા ન મોકલાય.
Safe Brows­ing Ex­tend­ed Re­port­ing Safe Browsing પેજ બ્લોક કરે ત્યારે, Chrome બ્લોક થયેલા પેજની સામગ્રી Googleના સર્વર પર મોકલી શકે છે. Privacy Magic આ સુવિધા બ્લોક કરે છે, જેથી કોઈ ડેટા ન મોકલાય.
Search Sug­gest ડિફોલ્ટ રીતે, Chrome તમે એડ્રેસ બારમાં જે ટાઇપ કરો છો તે ટાઇપ કરતી વખતે જ તમારા ડિફોલ્ટ સર્ચ એન્જિન (સામાન્ય રીતે Google search) પર મોકલે છે, ઑટો-સજેશન માટે. Privacy Magic આ સતત મોનિટરિંગ બ્લોક કરે છે, જેથી તમે "enter" દબાવો ત્યારે જ Chrome તમારી સર્ચ મોકલે.
Spelling Ser­vice Chrome "enhanced spell check" ઓફર કરે છે જે તમે ટાઇપ કરો છો તે Googleના સર્વર પર મોકલે છે. Privacy Magic આ વિકલ્પ અક્ષમ કરે છે અને Chromeને ફક્ત સ્થાનિક "basic spell check" વાપરવાની મંજૂરી આપે છે.

એડ ટાર્ગેટિંગ API અક્ષમ કરવી

API માનક વેબ બ્રાઉઝર Privacy Magic
Ad Mea­sure­ment API Ad Measurement API (અને સંબંધિત Private Aggregation API) તમારા બ્રાઉઝિંગ, તમે ક્લિક કરો છો તે જાહેરાતો અને અન્ય ખાનગી ડેટા જાહેરાત સર્વર પર મોકલે છે. Privacy Magic તમારા ડેટાનું રક્ષણ કરવા આ API અક્ષમ કરે છે.
Pro­tect­ed Au­di­ence API ડિફોલ્ટ રીતે, આ API Chrome દ્વારા જાહેરાતકર્તાઓ વતી તમારા ધ્યાન પર હરાજી ચલાવવા માટે ઉપલબ્ધ કરાય છે. Privacy Magic આ API અક્ષમ કરે છે જેથી તમારો બ્રાઉઝિંગ ડેટા આ રીતે વપરાય નહીં.
Top­ics API Chromeનું Topics API જાહેરાતકર્તાઓને એવા વિષયોની યાદી આપે છે જે કથિત રીતે તમને રસપ્રદ છે. Privacy Magic તે ડેટા ખાનગી રાખવા Topics API અક્ષમ કરે છે.
