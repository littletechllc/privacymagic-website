Shared Stor­age Shared Storage ನಿಮ್ಮ ಬ್ರೌಸಿಂಗ್ ಬಗ್ಗೆ ಡೇಟಾವನ್ನು ಒಗ್ಗೂಡಿಸಿ ಸಂಗ್ರಹಿಸಲು ಅನುಮತಿಸುವ ಬ್ರೌಸರ್ ವೈಶಿಷ್ಟ್ಯ. ಇದು ಗೌಪ್ಯತೆ-ಸಂರಕ್ಷಕ ಎಂದು ಹೇಳಲಾಗಿದ್ದರೂ, ಈ ವೈಶಿಷ್ಟ್ಯ ಬಲವಾದ ಗೌಪ್ಯತೆ ಕಳವಳಗಳನ್ನು ಹುಟ್ಟುಹಾಕಿತು ಮತ್ತು ಬ್ರೌಸರ್‌ಗಳಿಂದ ತೆಗೆದುಹಾಕಲಾಗುತ್ತಿದೆ. Privacy Magic Shared Storage ಎಲ್ಲಾ ವೆಬ್‌ಸೈಟ್‌ಗಳಲ್ಲಿ ನಿಷ್ಕ್ರಿಯಗೊಳಿಸಲಾಗಿದೆ ಎಂದು ಖಚಿತಪಡಿಸುತ್ತದೆ.
Shared Work­ers Shared Workers ಹಿನ್ನೆಲೆಯಲ್ಲಿ ಚಲಿಸುವ ಮತ್ತು ವೆಬ್‌ಸೈಟ್‌ಗಳ ನಡುವೆ ಹಂಚಿಕೊಳ್ಳಬಹುದಾದ ಕೋಡ್. Privacy Magic ಯಾವುದೇ ವೆಬ್‌ಸೈಟ್ ಲೋಡ್ ಮಾಡುವ ಪ್ರತಿ Shared Workerಗೆ ತನ್ನ ರಕ್ಷಣೆಗಳನ್ನು ಇಂಜೆಕ್ಟ್ ಮಾಡುತ್ತದೆ.
Web Work­ers Web Workers ವೆಬ್ ಪುಟದಲ್ಲಿ ಹಿನ್ನೆಲೆಯಲ್ಲಿ ಚಲಿಸುವ ಕೋಡ್. ಮುಖ್ಯ ಪುಟದ ಸ್ಕ್ರಿಪ್ಟ್‌ಗಳಂತೆಯೇ, web worker ಕೋಡ್ ಖಾಸಗಿ ಡೇಟಾವನ್ನು ಸೋರಿಸಬಹುದು. Privacy Magic ಪುಟದಲ್ಲಿನ ಪ್ರತಿ Web Workerಗೆ ತನ್ನ ರಕ್ಷಣೆಗಳನ್ನು ಇಂಜೆಕ್ಟ್ ಮಾಡುತ್ತದೆ, ಇದರಿಂದ ಟ್ರ್ಯಾಕರ್‌ಗಳು ಆ ರಕ್ಷಣೆಗಳನ್ನು ಬೈಪಾಸ್ ಮಾಡಲು Web Workers ಅನ್ನು ಬಳಸಲು ಸಾಧ್ಯವಾಗುವುದಿಲ್ಲ.

ಗೌಪ್ಯತೆ ಸಂಕೇತಗಳು

ನಿಮ್ಮ ಗೌಪ್ಯತೆಯನ್ನು ಸಾಧ್ಯವಿರುವ ಪ್ರತಿ ರೀತಿಯಲ್ಲೂ ಸುಧಾರಿಸುವಲ್ಲಿ ನಾವು ಆಸಕ್ತರಾಗಿದ್ದೇವೆ. ಆದ್ದರಿಂದ Privacy Magic ನೀವು ಭೇಟಿ ನೀಡುವ ವೆಬ್‌ಸೈಟ್‌ಗಳಿಂದ ಗೌಪ್ಯತೆ-ಪರ ನೀತಿಗಳನ್ನು ಬೇಡುವ ಸಂಕೇತವನ್ನು ಕಳುಹಿಸುತ್ತದೆ.

ಸಂಕೇತ ಪ್ರಮಾಣಿತ ವೆಬ್ ಬ್ರೌಸರ್‌ಗಳು Privacy Magic
Glob­al Pri­va­cy Con­trol Global Privacy Control ನಿಮ್ಮ ಡೇಟಾವನ್ನು ಮಾರಾಟ ಮಾಡಬೇಡಿ ಅಥವಾ ಹಂಚಿಕೊಳ್ಳಬೇಡಿ ಎಂದು ಸೂಚಿಸಲು ನೀವು ಭೇಟಿ ನೀಡುವ ವೆಬ್‌ಸೈಟ್‌ಗಳಿಗೆ ಕಳುಹಿಸಬಹುದಾದ ಸಂಕೇತ. ದುರದೃಷ್ಟವಶಾತ್, ಹೆಚ್ಚಿನ ವೆಬ್ ಬ್ರೌಸರ್‌ಗಳು ಡೀಫಾಲ್ಟ್ ಆಗಿ Global Privacy Control ಆದ್ಯತೆಯನ್ನು ಕಳುಹಿಸುವುದಿಲ್ಲ. Privacy Magic ನಿಮ್ಮ ಬ್ರೌಸರ್ ಪ್ರತಿ ವೆಬ್ ಪುಟ ಅಥವಾ ಎಂಬೆಡೆಡ್ ರಿಸೋರ್ಸ್‌ಗೆ ಪ್ರತಿ ವಿನಂತಿಯೊಂದಿಗೆ Global Privacy Control ಹೆಡರ್ ಕಳುಹಿಸುವುದನ್ನು ಖಚಿತಪಡಿಸುತ್ತದೆ. ಇದು ಪ್ರತಿ ಪುಟ ಮತ್ತು iframeನಲ್ಲಿ JavaScript ಸಂಕೇತವನ್ನೂ ಇಂಜೆಕ್ಟ್ ಮಾಡುತ್ತದೆ.

ಬ್ರೌಸರ್ ರಕ್ಷಣೆಗಳು

ಬ್ರೌಸರ್‌ಗಳು ವೆಬ್ ಪುಟಗಳನ್ನು ರೆಂಡರ್ ಮಾಡುವ ರೀತಿಯಲ್ಲಿ ಮಾತ್ರವಲ್ಲದೆ, ಪೋಷಕ ಕಂಪನಿಗೆ ಅಥವಾ ಮೂರನೇ ಪಕ್ಷದ ಜಾಹೀರಾತು ಕಂಪನಿಗಳಿಗೆ ಡೇಟಾ ಕಳುಹಿಸುವ ರೀತಿಯಲ್ಲಿಯೂ ಕೆಟ್ಟ ನಡವಳಿಕೆ ತೋರುತ್ತವೆ. Privacy Magic ಇಲ್ಲದಿದ್ದರೆ ನಿಮ್ಮ ಖಾಸಗಿ ಮಾಹಿತಿಯನ್ನು ಸೋರಿಸುತ್ತಿದ್ದ ವಿವಿಧ ಕೆಟ್ಟ ಬ್ರೌಸರ್ ನಡವಳಿಕೆಗಳನ್ನು ನಿಷ್ಕ್ರಿಯಗೊಳಿಸುತ್ತದೆ.

ಸೋರಿಕೆಯಾಗುವ ವೆಬ್ ವೈಶಿಷ್ಟ್ಯಗಳನ್ನು ನಿಷ್ಕ್ರಿಯಗೊಳಿಸುವುದು

ವೈಶಿಷ್ಟ್ಯ ಪ್ರಮಾಣಿತ ವೆಬ್ ಬ್ರೌಸರ್‌ಗಳು Privacy Magic
Hy­per­link Au­dit­ing ಪ್ರಮಾಣಿತ ಬ್ರೌಸರ್‌ಗಳಲ್ಲಿ ವೆಬ್‌ಸೈಟ್‌ಗಳು ನೀವು ಕ್ಲಿಕ್ ಮಾಡುವ ಲಿಂಕ್‌ಗಳೊಂದಿಗೆ ಟ್ರ್ಯಾಕಿಂಗ್ ಸರ್ವರ್‌ಗೆ "ಪಿಂಗ್" ಮಾಡಲು ಅನುಮತಿಸುವ ವೈಶಿಷ್ಟ್ಯವಿದೆ. Privacy Magic ಈ ಪಿಂಗ್ ಅನ್ನು ನಿಷ್ಕ್ರಿಯಗೊಳಿಸುತ್ತದೆ.
Third-Par­ty Cook­ies ಎಲ್ಲದರಲ್ಲೂ ಅತ್ಯಂತ ಪ್ರಸಿದ್ಧ ಟ್ರ್ಯಾಕಿಂಗ್ ವೈಶಿಷ್ಟ್ಯ. Chrome ಮೂರನೇ ಪಕ್ಷದ ಕುಕಿಗಳನ್ನು ಅನುಮತಿಸುತ್ತದೆ, ಇದು ನಿಮ್ಮನ್ನು ಸೈಟ್‌ನಿಂದ ಸೈಟ್‌ಗೆ ಟ್ರ್ಯಾಕ್ ಮಾಡಲು ಅನುಮತಿಸುತ್ತದೆ. Privacy Magic ಡೀಫಾಲ್ಟ್ ಆಗಿ ಮೂರನೇ ಪಕ್ಷದ ಕುಕಿಗಳನ್ನು ನಿಷ್ಕ್ರಿಯಗೊಳಿಸುತ್ತದೆ.
Web­RTC non-prox­ied UDP WebRTC ಇತರ ವೆಬ್ ಬಳಕೆದಾರರೊಂದಿಗೆ ನೇರವಾಗಿ ಸಂವಹನ ಮಾಡಲು ಅನುಮತಿಸುವ ವೆಬ್ ಬ್ರೌಸರ್ ಸಾಮರ್ಥ್ಯ. ದುರದೃಷ್ಟವಶಾತ್, ನೀವು ಬ್ರೌಸರ್ ಪ್ರಾಕ್ಸಿ ಬಳಸುತ್ತಿದ್ದರೆ, ಪ್ರಮಾಣಿತ Chrome-ಆಧಾರಿತ ಬ್ರೌಸರ್‌ಗಳು ಪ್ರಾಕ್ಸಿಯ ಹೊರಗೆ WebRTC ಸಂವಹನಗಳನ್ನು ಸೋರಿಸುತ್ತವೆ. Privacy Magic ಅದನ್ನು ಬಳಸುವ ವೆಬ್‌ಸೈಟ್‌ಗಳಲ್ಲಿ WebRTC ಕಾರ್ಯನಿರ್ವಹಿಸುವುದನ್ನು ಅನುಮತಿಸುತ್ತಾ, WebRTC ಸೋರಿಕೆಗಳನ್ನು ನಿರ್ಬಂಧಿಸುತ್ತದೆ.

ಆಕ್ರಮಣಕಾರಿ ಕ್ಲೌಡ್ ಸೇವೆಗಳನ್ನು ನಿಷ್ಕ್ರಿಯಗೊಳಿಸುವುದು

ಸೇವೆ ಪ್ರಮಾಣಿತ ವೆಬ್ ಬ್ರೌಸರ್‌ಗಳು Privacy Magic
Al­ter­nate Er­ror Pages ಡೀಫಾಲ್ಟ್ ಆಗಿ, ದೋಷ ಸಂಭವಿಸಿದಾಗ Chrome ಪರ್ಯಾಯ ದೋಷ ಪುಟಗಳನ್ನು ತೋರಿಸುತ್ತದೆ. ಈ ಪುಟಗಳನ್ನು ತೋರಿಸಲು, ನೀವು ಯಾವ ಪುಟಗಳನ್ನು ಭೇಟಿ ನೀಡುತ್ತಿದ್ದೀರಿ ಎಂಬ ಡೇಟಾವನ್ನು Googleನ ಸರ್ವರ್‌ಗಳಿಗೆ ಕಳುಹಿಸಲಾಗುತ್ತದೆ. Privacy Magic ಈ ಪರ್ಯಾಯ ದೋಷ ಪುಟಗಳನ್ನು ನಿಷ್ಕ್ರಿಯಗೊಳಿಸುತ್ತದೆ ಇದರಿಂದ ಯಾವುದೇ ಡೇಟಾ ಕಳುಹಿಸಲಾಗುವುದಿಲ್ಲ.
Safe Brows­ing Ex­tend­ed Re­port­ing Safe Browsing ಪುಟವನ್ನು ನಿರ್ಬಂಧಿಸಿದಾಗ, Chrome ನಿರ್ಬಂಧಿತ ಪುಟದ ವಿಷಯವನ್ನು Googleನ ಸರ್ವರ್‌ಗಳಿಗೆ ಕಳುಹಿಸಬಹುದು. Privacy Magic ಈ ವೈಶಿಷ್ಟ್ಯವನ್ನು ನಿರ್ಬಂಧಿಸುತ್ತದೆ, ಇದರಿಂದ ಯಾವುದೇ ಡೇಟಾ ಕಳುಹಿಸಲಾಗುವುದಿಲ್ಲ.
Search Sug­gest ಡೀಫಾಲ್ಟ್ ಆಗಿ, ನೀವು ಟೈಪ್ ಮಾಡುತ್ತಿರುವಾಗ ಆಟೋ-ಸಲಹೆಗಳನ್ನು ನೀಡಲು, Chrome ವಿಳಾಸ ಪಟ್ಟಿಯಲ್ಲಿ ನೀವು ಟೈಪ್ ಮಾಡುವ ಯಾವುದನ್ನೂ ನಿಮ್ಮ ಡೀಫಾಲ್ಟ್ ಸರ್ಚ್ ಎಂಜಿನ್‌ಗೆ (ಸಾಮಾನ್ಯವಾಗಿ Google search) ಕಳುಹಿಸುತ್ತದೆ. Privacy Magic ಈ ನಿರಂತರ ಮಾನಿಟರಿಂಗ್ ಅನ್ನು ನಿರ್ಬಂಧಿಸುತ್ತದೆ, ಇದರಿಂದ ನೀವು "enter" ಒತ್ತಿದಾಗ ಮಾತ್ರ Chrome ನಿಮ್ಮ ಹುಡುಕಾಟವನ್ನು ಕಳುಹಿಸುತ್ತದೆ.
Spelling Ser­vice Chrome ನೀವು ಟೈಪ್ ಮಾಡುವುದನ್ನು Googleನ ಸರ್ವರ್‌ಗಳಿಗೆ ಕಳುಹಿಸುವ "enhanced spell check" ಅನ್ನು ನೀಡುತ್ತದೆ. Privacy Magic ಈ ಆಯ್ಕೆಯನ್ನು ನಿಷ್ಕ್ರಿಯಗೊಳಿಸುತ್ತದೆ ಮತ್ತು Chrome ಸ್ಥಳೀಯ "basic spell check" ಅನ್ನು ಮಾತ್ರ ಬಳಸಲು ಅನುಮತಿಸುತ್ತದೆ.

ಜಾಹೀರಾತು ಗುರಿ APIಗಳನ್ನು ನಿಷ್ಕ್ರಿಯಗೊಳಿಸುವುದು

API ಪ್ರಮಾಣಿತ ವೆಬ್ ಬ್ರೌಸರ್‌ಗಳು Privacy Magic
Ad Mea­sure­ment API Ad Measurement API (ಮತ್ತು ಸಂಬಂಧಿತ Private Aggregation API) ನಿಮ್ಮ ಬ್ರೌಸಿಂಗ್, ನೀವು ಕ್ಲಿಕ್ ಮಾಡುವ ಜಾಹೀರಾತುಗಳು ಮತ್ತು ಇತರ ಖಾಸಗಿ ಡೇಟಾವನ್ನು ಜಾಹೀರಾತು ಸರ್ವರ್‌ಗಳಿಗೆ ಕಳುಹಿಸುತ್ತದೆ. Privacy Magic ನಿಮ್ಮ ಡೇಟಾವನ್ನು ರಕ್ಷಿಸಲು ಈ APIಗಳನ್ನು ನಿಷ್ಕ್ರಿಯಗೊಳಿಸುತ್ತದೆ.
Pro­tect­ed Au­di­ence API ಡೀಫಾಲ್ಟ್ ಆಗಿ, ಈ API ಅನ್ನು Chrome ಜಾಹೀರಾತುದಾರರ ಪರವಾಗಿ ನಿಮ್ಮ ಗಮನದ ಮೇಲೆ ಹರಾಜು ನಡೆಸಲು ಲಭ್ಯವಾಗುವಂತೆ ಮಾಡುತ್ತದೆ. Privacy Magic ನಿಮ್ಮ ಬ್ರೌಸಿಂಗ್ ಡೇಟಾವನ್ನು ಈ ರೀತಿ ಬಳಸದಂತೆ ಈ API ಅನ್ನು ನಿಷ್ಕ್ರಿಯಗೊಳಿಸುತ್ತದೆ.
