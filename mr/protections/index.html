Shared Stor­age Shared Storage हे ब्राउझर वैशिष्ट्य आहे जे तुमच्या ब्राउझिंगबद्दलचा डेटा एकत्रित आणि गोळा करू देते. जरी ते गोपनीयता-संरक्षक असल्याचा दावा केला गेला होता, तरी या वैशिष्ट्याने गंभीर गोपनीयता चिंता निर्माण केल्या आणि ते ब्राउझरमधून काढले जाणार आहे. Privacy Magic खात्री करते की Shared Storage सर्व वेबसाइट्सवर अक्षम आहे.
Shared Work­ers Shared Workers हे बॅकग्राउंडमध्ये चालणारे कोड आहेत जे वेबसाइट्समध्ये शेअर केले जाऊ शकतात. Privacy Magic कोणत्याही वेबसाइटने लोड केलेल्या प्रत्येक Shared Worker मध्ये तिची संरक्षणे इंजेक्ट करते.
Web Work­ers Web Workers हे वेब पेजवर बॅकग्राउंडमध्ये चालणारे कोड आहेत. मुख्य पेजच्या स्क्रिप्ट्सप्रमाणे, web worker कोड खाजगी डेटा लीक करू शकतो. Privacy Magic पेजवरील प्रत्येक Web Worker मध्ये तिची संरक्षणे इंजेक्ट करते, जेणेकरून ट्रॅकर्स Web Workers वापरून त्या संरक्षणांना बायपास करू शकणार नाहीत.
